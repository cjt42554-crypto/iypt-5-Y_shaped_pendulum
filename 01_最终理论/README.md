# 理论成熟基线

本目录保存当前已接受的理论基线。“最终理论”是沿用的路径名称，不表示理论已经不可修订，也不表示已经获得数值或实验验证。

## 内容

1. [`01-前向预测理论.md`](01-前向预测理论.md)：给定模型参数与初态后，定义系统运动的前向理论。
2. [`02-前向预测理论的数值计算理论.md`](02-前向预测理论的数值计算理论.md)：说明前向理论的离散、求解和数值判据。
3. [`03-结构性理论.md`](03-结构性理论.md)：研究模态、共振、稳定性及其他结构性质。

## 基线约定

- 本目录表达“当前接受版本”，不自动表达预测精度、数值资格或实验有效性。
- 新理论修订先进入 [`../90_候选工作区/current/`](../90_候选工作区/current/)；回写时应记录来源、差异、验证和结论上限。
- 当前资格和下一步只以 [`../00_项目控制/STATUS.md`](../00_项目控制/STATUS.md) 为准。
