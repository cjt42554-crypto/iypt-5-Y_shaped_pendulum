# 理论

本目录包含 Y 形摆研究的三份理论文档：

1. [`01-前向预测理论.md`](01-前向预测理论.md)：定义连续柔索、理想环面和有限质量结点三自由度模型；包含释放相容的强解类、张紧线性能量解及有限时间撤力。
2. [`02-前向预测理论的数值计算理论.md`](02-前向预测理论的数值计算理论.md)：说明离散、求解、事件判定和数值误差控制。
3. [`03-结构性理论.md`](03-结构性理论.md)：研究模态、共振、稳定性及其他结构性质。

三份文档分别承担物理模型、数值方法和结构分析。前向正文的有限质量结点分支不能直接理解为已有正式运行模式；数值文档的覆盖范围和实现差距需单独核对。目录名称不构成数值收敛、预测精度或实验有效性的证明；相关结论必须由相应验证支持。
