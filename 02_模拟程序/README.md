# 模拟程序

按研究问题使用下列唯一入口；表中的模型适用域不同，不按日期或版本号互相替代。

| 用途与身份 | 入口 | 使用边界 |
| --- | --- | --- |
| 当前前向预测 | [y_pendulum_forward_solver](01_前向预测数值求解器/y_pendulum_forward_solver/README.md) | 同一分派入口选择连续柔索 `FWD-CABLE-1.0`、理想环面 `FWD-TORUS-1.0` 或有限质量结点 `YP-FWD-J3-v1`；三种初态与适用域独立 |
| 当前结构图谱实现 | [pattern_atlas](03_结构性理论分析程序/pattern_atlas/README.md) | 绑定正式环面后端，研究理想模型内部的调谐、相位和闭合；历史源锁与当前理论/源码有三项失配，重跑前须完成来源审计 |
| 无接触静态参考 | [离散杆—刚体参考模型](04_离散杆刚体无接触静态参考模型/README.md) | 仅位置—姿态保守静态实现与运行证据；无接触、摩擦或动力学资格，不能替代前向柔索 |
| RC1 历史高保真参考 | [RC1 状态说明](02_第一性原理高保真模拟器/Y-Pendulum-Simulator-v1.0.0-rc1/STATUS.md) | 保留历史模型、配置、界面与回归；整体数值资格仍为 NO-GO，不作为已验证的通用高保真预测器 |
| 独立结构核验方法 | [torus_structure_analysis.py](03_结构性理论分析程序/torus_structure_analysis.py) | 保留独立理想方程核验，支撑结构理论第 5.5、5.6 及 8.4 节的周期、补偿和六周期张紧域扫描；不是第二套生产前向入口 |

独立结构脚本包含 `first_exit`、37×43 初态的 `taut_domain_scan` 及几何设计图；这些功能并非 `pattern_atlas` 的相位/闭合图谱的重复副本，因此保留原路径和源码。其结果只针对理想方程与有限采样窗口；没有新增计算、装置校准或实验验证。当前来源失配的待办仍见 [current](../00_项目管理/交接说明_current.md)，本次目录整理不更新源锁或继承旧图谱资格。

每个子项目自行声明依赖、入口、配置、测试和输出。跨层比较必须记录模型身份和输入映射；程序运行结果不自动构成装置级物理或实验验证。

仓库整体高保真数值资格状态仍为 `HF_NUMERICAL_QUALIFICATION_NO_GO`；无接触静态参考的结论上限仍为 `FORMAL_STATIC_REFERENCE_IMPLEMENTATION_AND_RUNTIME_EVIDENCE_ONLY`。导航清理不改变这些结论。
