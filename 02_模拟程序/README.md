# 程序成熟基线

本目录保存当前已接受的程序基线。三个子项目对应研究的不同计算层级，不应仅凭目录名互相替代其物理身份。

## 子项目

1. [`01_前向预测数值求解器/`](01_前向预测数值求解器/)：实现前向预测理论的数值求解。
2. [`02_第一性原理高保真模拟器/`](02_第一性原理高保真模拟器/)：实现更细致的第一性原理或高保真模型。
3. [`03_结构性理论分析程序/`](03_结构性理论分析程序/)：实现结构性理论的计算与分析。

## 程序契约

- 每个子项目自行声明依赖、启动入口、配置、测试和输出格式；跨子项目比较必须记录各自模型身份和输入映射。
- 源码、配置、测试与示例应留在对应子项目；大体积运行结果、审查证据和候选修订不直接混入成熟源码。
- 新实现默认进入 [`../90_候选工作区/current/`](../90_候选工作区/current/)；只有明确映射并复验的组件才回写本目录。
- 当前资格和下一步见 [`../00_项目控制/STATUS.md`](../00_项目控制/STATUS.md)。
