# HF-v2 验收矩阵

## 1. 证据等级

所有阶段报告必须区分：

1. 源码与目录检查；
2. 单元实现测试；
3. 数值算法验证；
4. 模型间比较；
5. 物理验证；
6. 实验验证。

没有实验数据时，最高只能声明数值资格或条件性物理一致性，不能声明实验预测已经验证。

## 2. 预冻结尺度

每个目标运行前生成 `contracts/acceptance_manifest.json`，至少冻结：

- 特征长度 $L_*$；
- 特征时间 $T_*$；
- 特征速度 $V_*=L_*/T_*$；
- 特征力 $F_*$；
- 特征能量 $E_*=F_*L_*$；
- 网格层级；
- 时间步层级；
- 绝对与相对容差；
- 多种子集合；
- 接触候选集策略；
- 通过/失败判据。

看到目标结果后不得直接覆盖该清单。任何门槛变更必须生成新版本，并说明是数学修正、尺度修正还是结果驱动调参。

## 3. P1 纯物理核

| 项目 | 最低证据 |
|---|---|
| 轴向力—能量一致性 | 中心有限差分与解析梯度相对误差在步长收敛区间内下降，最终建议阈值不高于 `5e-7` |
| 弯曲力—能量一致性 | 同上；必须覆盖直杆、平面弯曲、三维弯曲和接近奇点但仍合法的状态 |
| 作用—反作用 | 内力合力与关于任意原点的合矩接近机器精度，使用尺度化阈值 |
| 客观性 | 刚体平移和共同旋转不改变内能；力按旋转协变 |
| 单边性 | 所有压缩段最终轴力为零，不能只在输出层截断 |
| 被动性 | 黏性耗散率和单边卸载附加耗散均非负 |
| 姿态群性质 | 连续群更新后 $R^{\mathsf T}R-I$ 与 $\det R-1$ 保持在舍入误差尺度 |

## 4. 静态 KKT

建议预冻结的初始绝对下限为：

- 原始穿透：不大于 `1e-10 m`；
- 对偶负值：不大于 `1e-10 N`；
- 力平衡：不大于 `max(1e-8 N, 1e-8 F_*)`；
- 互补：不大于 `max(1e-12 N*m, 1e-10 E_*)`。

这些是候选起点，不是不可修改的物理常数。修改必须发生在目标结果出现前，或由独立舍入/尺度分析证明。

静态通过还必须满足：

- 每个活动接触有可追踪身份；
- 最近点见证唯一且可微，或明确使用非光滑方法；
- 活动约束雅可比秩被审计；
- 至少有一个独立于主优化器的 KKT 复算；
- 二阶稳定性不能只看优化器退出码；
- 多种子选择依据势能、KKT 和稳定性，而不是依据接近预期轨迹。

## 5. P3R2 静态接触数值认证

P3R2 不能把不同单位的广义站立分量只压缩成一个无来源说明的标量。每个种子至少必须提交以下机器证据。

### 5.1 分量级站立证据

- 完整广义坐标身份和顺序；
- 平移站立残差分量，单位 N；
- 转动站立残差分量，单位 N·m；
- 触发最大值的分量身份；
- 预冻结特征长度 $L_*$、特征力 $F_*$ 和特征能量 $E_*$；
- 坐标尺度、残差尺度和无量纲化公式；
- 主求解阶段前后及 KKT 恢复阶段前后的对应向量；
- 原始门和无量纲门的逐项 PASS/FAIL。

$L_*$ 必须由模型几何或组装合同确定，不能由已观察失败值反推。平移和转动分量既要分别报告，也要在统一无量纲广义坐标中审计。

### 5.2 历史回归门

P3R2 必须保持并通过 P3R 的旧标量回归门：

`stationarity_residual_N <= 1.0e-8`

该名称保留仅用于历史回归。P3R2 新报告必须同时说明其中各分量的真实单位，不得把通过解释为旧命名已经具有严格量纲一致性。

当前 35° 目标、原三个种子、接触身份、目标位置、乘子和旧阈值均不可修改。只有三个原种子全部通过，才能继续评价新资格目标。

### 5.3 单一复合算法

允许的算法形式是预冻结的单一复合算法，例如：

1. 固定 SLSQP 主阶段；
2. 对每个种子都执行的固定 KKT 恢复阶段。

第二阶段不得按第一阶段结果选择是否启用。活动集选择、规范投影、KKT 方程、Hessian 来源、线性系统、最大迭代数、阻尼/线搜索、可行性保护和失败状态必须在任何新资格目标运行前冻结。

算法不得使用：

- fallback 求解器；
- 随机重启；
- 失败后新增种子；
- 结果驱动容差放宽；
- 罚刚度或柔顺接触兜底。

### 5.4 对偶和二阶认证

- 规范乘子继续由独立 NNLS 或等价确定性方法重构；
- 逐身份对偶区间的 LP 必须使用与分量级 KKT 完全一致的尺度合同；
- LP 不可行时，可能支撑和必然支撑标记为“未认证”，不能解释为空物理支撑集；
- 真实一侧临界锥和二阶方向曲率继续独立于主求解器；
- KKT 恢复不能改变正式接触登记或删除弱活动约束。

### 5.5 新资格目标与通过规则

至少两个新目标必须在第一次运行前进入清单和 Git 提交，每个至少三个确定性种子。其中至少包含一个非镜像对称双接触目标和一个不同几何或载荷尺度目标。

G3R2 通过要求：

- 旧对称结构回归通过；
- 当前 35° 三种子回归通过；
- 两个新目标的全部冻结种子通过；
- 分量级 KKT、对偶区间、有效域、Jacobian、作用—反作用、临界锥、二阶门和 P2 只读性全部通过；
- 两次独立证据生成字节一致。

任意一个种子失败，整门为 NO-GO。优化器退出码和候选接近解析位置均不能替代上述独立门。

## 6. 平滑动力学

| 项目 | 通过原则 |
|---|---|
| 时间阶 | 在解析或高精度基准的渐近区间，步长减半误差比接近二阶；建议至少大于 `3` |
| 保守能量 | 固定物理时窗内能量误差随步长减半呈二阶下降；不以一次小漂移替代阶数证据 |
| 被动耗散 | $\Delta E + D - W_{\mathrm{ext}}$ 随步长收敛，且不存在持续正的未解释功率 |
| 动量/角动量 | 在相应对称基准中随步长收敛；有外力时使用完整冲量平衡 |
| 姿态 | 不依赖每步强制归一化才能保持合法 |
| 非线性求解 | 记录残差、迭代数、拒绝步和最终失败；不得隐藏在 fallback 中 |

## 7. 单边张力活动集

必须覆盖：

- 始终张紧；
- 初始松弛；
- 单次松弛；
- 单次重新张紧；
- 多段同时切换；
- 近切触但不发生切换；
- 网格加密下事件/活动集稳定性。

通过要求：

- 每个接受步轴力非负；
- 活动集切换不依赖输出采样网格；
- 无伪能量注入；
- 时间步减半后切换时间和宏观轨迹收敛；
- 切触与真正穿越在算法层可区分，而不是事后状态标签修补。

## 8. 动态接触

P6 开启后至少验证：

- 非穿透；
- 法向冲量非负；
- 冲量—相对速度互补；
- 冲击前后动量平衡；
- 恢复系数合同；
- 接触耗散与数值耗散分离；
- 同时接触和接触集合退化；
- 时间步、接触候选集和网格加密；
- 无摩擦时切向冲量为零。

仅“没有崩溃”或“视觉上没有穿透”不构成通过。

## 9. RC1 对照

RC1 对照分三类：

1. **共同模型域**：始终张紧、无接触、相同材料和摆球参数；应比较收敛极限；
2. **模型身份不同**：RC1 双侧压缩正则与 HF-v2 张力单边；差异应被解释，不要求一致；
3. **RC1 超出物理域**：出现自穿透或依赖 guard 终止；HF-v2 不应复制该行为。

禁止把 RC1 单条轨迹作为 HF-v2 的绝对真值。

## 10. 三锚点门

`4:3`、`3:2`、`2:1` 只有在单元、静态和小型动力学基准通过后才能运行。每个锚点至少要求：

- 三层空间网格；
- 三层时间步；
- 力、能量、活动集和接触证据；
- 公共摆球观测量；
- 模型身份差异说明；
- 不以目标频率比接近程度作为数值正确性标准。

## 11. 架构验收

- 新核心不存在对 UI、I/O、分析和正式验证模块的反向依赖；
- 单个核心文件原则上不超过约 `800` 行；超过时必须说明为何不能按物理职责拆分；
- 单个公共函数原则上只承担一个方程或算法职责；
- `solver` 不包含哈希、绘图、HDF5、CPU 核检测或报告生成；
- 不存在自动求解器瀑布；
- 不存在为了通过测试而静默放宽物理域；
- 每个模型开关都会改变明确的模型身份或配置合同。

## 12. 性能验收

性能优化只能发生在数值正确性之后。要求：

- 先有剖析数据；
- 优化前后轨迹和资格证据等价；
- 不通过减少守卫、降低精度或跳过 KKT 获得加速；
- 大数组分配、稀疏装配和局部接触查询有独立基准；
- 性能结果绑定硬件、线程数、Python/NumPy/SciPy 版本和配置。
