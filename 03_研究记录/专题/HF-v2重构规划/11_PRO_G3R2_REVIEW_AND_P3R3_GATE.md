## 3. 两个新目标的准入失效

### 3.1 非对称 32/41 度双接触参考

解析参考满足：

- 两项预登记摆球接触间隙为零；
- 规范乘子约为 `0.8443577931300781 N` 与 `0.9487835290595384 N`，均为正且不相等；
- 一阶 KKT、互补、支撑身份、严格有效域、作用—反作用和 Jacobian 审计通过。

但真实一侧临界锥的最小支持切向曲率为：

`-4.816125831771666`

独立方向曲率和矩阵 Hessian 交叉检查均得到同号、同量级结果，最大交叉误差约 `1.65e-5`。该参考因此是明显不稳定驻点，不是局部能量极小值。

正偏和反偏种子确定性进入两个镜像稳定分支。稳定分支的摆球横向位移约为 `+/-0.00749908 m`，旋转分量约为 `+/-0.07546885 rad`，最小临界锥曲率约为 `0.0317656468880674`。偏置种子离开不稳定参考不是“未收敛到正确稳定解”，而是局部最小化算法对不稳定驻点扰动的预期行为。

### 3.2 1.4 倍几何尺度参考

解析参考同样满足精确位置、一阶 KKT、正乘子、接触身份和严格有效域，但最小支持切向曲率为：

`-0.0022739949514351543`

独立方向曲率和矩阵 Hessian 的最大交叉误差约 `6.15e-6`，仍明确给出负曲率。该参考也是不稳定驻点。

两个偏置种子确定性进入镜像稳定分支，横向位移约为 `+/-0.001181709 m`、旋转分量约为 `+/-0.008496954 rad`；稳定分支的最小临界锥曲率约为 `0.00402044687638639`，KKT 与支撑身份通过。它们只因不再贴合冻结的不稳定参考而被判失败。

### 3.3 科学含义

P3R2 协议把“目标参考有效性”和“算法从多种子恢复该参考”合并为同一个资格门。由于两个参考在第一次结果中都被证明不稳定，目标套件无法独立区分：

- 求解算法失败；
- 目标参考不是局部稳定平衡；
- 多稳态系统中种子进入另一稳定分支。

因此，冻结 G3R2 NO-GO 的形式裁决必须保持，但其科学上限只能是：

`0.5-CONTACT-CANDIDATE` 未通过该冻结目标套件。

它不能被解释为静态刚性无摩擦接触算法整体失败，更不能否定物理路线。

## 4. 非对称稳定分支的 LP 自洽性矛盾

P3R2 的对偶区间 LP 对近活动约束求解：

`|gradient - J^T lambda| <= allowed_raw, lambda >= 0`

同一审计先用尺度化 NNLS 构造规范乘子，再以该乘子计算驻定残差。一个非对称稳定偏置分支记录：

- 规范乘子 `0.4237299671298871 N` 与 `0.4770506707496999 N`，均为正；
- 最大原始驻定分量 `4.163336342344337e-16`；
- 平移分量允许带 `9.9844218e-9 N`；
- 转动分量允许带 `8.985979620000002e-9 N*m`；
- 原始穿透 `2.0816681711721685e-17 m`；
- 互补残差 `1.3240815964479789e-17 N*m`。

由定义可知，上述规范乘子本身就是 LP 的显式可行见证：它非负，且其驻定残差比允许带小约七个数量级。尽管如此，提交证据记录 `dual_interval_feasible=false`，上下界均为 `NOT_A_NUMBER`，并据此把 `possible_supported_ids` 和 `mandatory_supported_ids` 清空。

因此该 LP 结果与自身输入及已保存见证不相容。仅凭 GitHub 静态复审不能判定根因究竟是 HiGHS 的缩放/预处理、约束量纲条件、状态传播还是序列化，但以下结论已经确定：

- 该分支的“LP 不可行”不能被视为数学不可行证书；
- P3R3 必须在调用 LP 前后直接验证规范乘子的全部不等式松弛；
- 若显式见证满足冻结不等式，LP 后端不得返回不可行并清空支撑身份；
- 区间端点还须由一个独立方法复核，而不是重复调用同一数值后端。

这不追溯改变 G3R2 的 `0/3`，因为该目标的解析参考稳定性和参考一致性门已经失败；它只阻止错误地把 LP 输出解释为稳定分支不存在 KKT 支撑。

## 5. 投影恢复的 Jacobian 闭合缺口

恢复残差包含状态相关投影：

`P(q)^T r(q)`

其中 `P(q)` 由当前旋转向量、`SO(3)` 右 Jacobian和附件规范方向重建。当前 Newton 矩阵使用：

`P(q)^T H_L(q, lambda)`

但源码没有显式加入：

`d(P(q)^T)/dq * r(q)`

因此现有实现尚未证明它是所定义复合残差的精确 Newton Jacobian。靠近驻定点时遗漏项可能很小，且本轮 35 度回归和多个分支确实收敛；所以该缺口不构成本轮目标不稳定的原因，也不否定已观察的数值修复效果。

P3R3 必须二选一：

1. 补齐投影导数并把方法保持为精确 Newton；或
2. 明确将其定义为投影拟 Newton，并对完整复合残差的解析/构造 Jacobian 做多步长中心差分复核，冻结可接受误差和失败关闭规则。

恢复线搜索还应把活动乘子非负性作为候选可接受条件，或在协议中给出保持非负性的等价证明；不能只依赖最终外部审计发现负乘子。

## 7. P3R3 预冻结强制控制

### 7.1 历史工件不可变

必须逐字节保留 P3/G3、P3R/G3R、P3R2/G3R2 的协议、清单、目标、种子、源码绑定、报告、指标、状态和哈希。不得在同一协议内修正 P3R2 的两个解析参考、种子、算法或 LP 结果后重跑并改判。

P3R2 两个不稳定参考及其已发现稳定分支均已被观察，只能作为历史诊断或回归，不能充当 P3R3 的未观察资格目标。

### 7.2 独立目标准入门

在冻结任何资格种子、且在任何资格目标运行前，每个候选参考必须先通过独立 `TARGET_ADMISSIBILITY`：

1. 坐标、模型、组装、接触登记和规范方向身份完整绑定；
2. 严格套筒有效域内部性和非活动接触正间隙；
3. 预期接触身份、近活动秩、正乘子支撑和规范乘子可行见证；
4. 分量级 KKT、互补、作用—反作用和 P2 只读审计；
5. 真实一侧临界锥的最小曲率严格大于预冻结正裕量；
6. 矩阵拉格朗日 Hessian与独立方向有限差分曲率交叉检查；
7. 规范自由度移除方式和临界方向定义显式记录；
8. 预冻结的局部稳定分支身份与局部盆地/邻域证书。

若参考未通过准入，状态必须为 `TARGET_INVALID`，不得把它计作算法种子失败，也不得继续运行该目标的资格种子。目标准入失败可以阻断 G3R3，但必须与 `ALGORITHM_SEED_FAIL` 分开报告。

### 7.3 对偶区间认证

P3R3 必须：

- 直接保存规范乘子作为 LP 可行见证；
- 逐分量保存 `gradient - J^T lambda`、允许带、上下不等式松弛和最小松弛；
- 在调用 LP 前后验证见证；见证可行时，后端“不可行”必须变成 `CERTIFIER_INTERNAL_INCONSISTENCY` 并失败关闭；
- 使用冻结的无量纲/预缩放形式，避免力与力矩分量条件差；
- 记录 HiGHS 原始状态、消息、预处理设置和缩放身份；
- 对低维双接触区间使用独立解析/顶点方法或不同数值后端复核端点；
- 禁止通过结果驱动放宽允许带、关闭预处理或更换后端来追求 PASS。

### 7.4 恢复阶段闭合

必须冻结精确 Newton 或拟 Newton 身份，并对完整复合残差的 Jacobian 做独立多步长复核。活动集、规范投影、Hessian、线性系统、乘子非负性、非活动间隙、有效域、线搜索和失败状态均须在目标结果前固定。

### 7.5 新资格目标与种子

P3R3 至少需要两个新的、预冻结且未观察的静态稳定双接触目标，每个至少三个确定性种子：

1. 一个非镜像对称目标，两个正乘子不相等；
2. 一个改变几何或载荷尺度的目标。

每个目标必须先通过 `TARGET_ADMISSIBILITY`，再冻结参考、局部分支身份、局部盆地半径、尺度化种子扰动和全部验收门。资格种子必须位于预认证局部盆地内；不能用跨盆地全局多稳态差异检验“回到同一局部稳定分支”的算法性质。

当前 35 度三个历史种子继续作为不可变回归，并保持旧 `1.0e-8` 混合标量门。任一历史回归失败，G3R3 必须 NO-GO。

## 8. 必须分开的提交边界

P3R3 至少形成以下三个有序提交：

1. **P3R3 预冻结提交**：新身份、协议、机器清单、目标准入定义、对偶见证合同、恢复 Jacobian 合同、回归角色和新目标生成规则；此时所有新资格目标运行数为零；
2. **P3R3 实现/准入工具提交**：独立包、测试、准入器、对偶认证器和证据生成器；仍不得包含新资格种子结果；允许使用已观察 P3R2 分支做明确标记的诊断回归；
3. **G3R3 证据提交**：前两项进入 Git 历史后，才冻结并运行通过准入的新资格目标种子，提交 JSON、原始报告和人类报告。

若没有至少两个参考通过目标准入，不得伪造或强行推进 G3R3 算法资格；应提交 `TARGET_SUITE_NOT_ADMISSIBLE` 并停止复审。

## 9. 禁止事项

- 改写任何历史 G3/G3R/G3R2 NO-GO；
- 修改 P3R2 两个目标、参考、种子、阈值、报告、指标或哈希；

- 把 `TARGET_INVALID` 计作算法种子失败或反向把算法失败隐藏为目标无效；
- 在显式可行见证存在时接受 LP 的不可行输出；
- 事后调节 LP 缩放、预处理、容差、种子、盆地半径或临界锥裕量；
- 增加求解器瀑布、随机重启、罚刚度、柔顺接触、摩擦、恢复系数或冲量；
- 修改 P2 轴向、弯曲、刚体、质量、重力、浮力或无接触静力方程；
- 修改正式 `01_最终理论/**`、`02_模拟程序/**`、顶层 `AGENTS.md`、公共 API、HDF5 或 UI；
- 开始 P4、P5、P6、动力学或正式提升。
