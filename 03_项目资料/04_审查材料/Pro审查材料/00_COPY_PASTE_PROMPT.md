# 可直接复制给 Pro 的审查提示词

请审查我上传的 Y 形摆四层研究包。

你没有本项目的先前对话记忆，也不能访问我的本地文件。请只依据上传包内容。先完整阅读 00_PRO_REVIEW_GUIDE.md，再读 01_ALL_IN_ONE_THEORY_AND_HANDOFF.md 和分层目录。

项目定位是单人使用的个人科研计算工具/可修改原型，不是生产发布软件。不要让 Git、wheel/sdist、ZIP、恶意 JSON、TOCTOU、crash-atomic、复杂 manifest 或不可伪造证书链阻塞科学验收；已经存在的相关防护可以审阅，但这不是本次重点。

请严格分开：

1. 前向预测理论；
2. 前向预测数值计算理论和程序；
3. 第一性原理高保真模拟；
4. 结构性理论。

重点独立核验物理方程、量纲、能量、张力/轴力、事件、接触守卫、数值实现一致性、代表性敏感性、性能等价性，以及结构性正规形和有限振幅结论。

输出：

1. 四层各自 GO / CONDITIONAL GO / NO-GO；
2. 四层隔离判定；
3. 面向个人科研计算目标的总判定；
4. P0/P1/P2 问题表；
5. 每项的文件、章节/函数、反例、影响、最小修正、是否必须重跑长 HF；
6. 你独立复算通过的公式和数字；
7. 仍需实验验证的结论；
8. 按物理收益排序的下一步建议。

不要仅摘要，也不要因为没有真实实验就否定全部理论；请区分解析正确性、数值证据、HF 机制证据和实验验证。
