# 项目资料成熟基线

本目录保存已经接受的说明、协议、技术文档、审查材料、验证证据和历史归档。它不用于存放尚未验收的活动候选。

## 现有分类

1. [`01_项目总览与交付说明/`](01_项目总览与交付说明/)：项目范围、交付和导航。
2. [`02_阶段说明与验收/`](02_阶段说明与验收/)：阶段目标、验收口径和结论边界。
3. [`03_使用说明与技术文档/`](03_使用说明与技术文档/)：运行、接口和技术说明。
4. [`04_审查材料/`](04_审查材料/)：独立审查、复现和裁决材料。
5. [`05_验证证据与研究结果/`](05_验证证据与研究结果/)：计算、数值和实验结果及其证据。
6. [`06_历史版本与发布归档/`](06_历史版本与发布归档/)：冻结版本和发布归档。
7. [`07_开发与发布元数据/`](07_开发与发布元数据/)：开发、构建和发布所需元数据。

## 资料契约

- 原始数据、处理后数据、配置、脚本、结果和结论应保持可追踪关系。
- 历史冻结证据保留其生成时路径和身份，不通过批量改写制造新的证据身份。
- 活动候选的管理记录与新证据先进入 [`../90_候选工作区/current/`](../90_候选工作区/current/)；被接受后再按类别归档到本目录。
- 当前状态见 [`../00_项目控制/STATUS.md`](../00_项目控制/STATUS.md)。
