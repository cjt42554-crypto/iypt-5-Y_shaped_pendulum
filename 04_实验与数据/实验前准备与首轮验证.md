# 实验前准备与首轮验证

本文把首轮实验所需输入和判据固定下来。实际软件验收状态、证据和未完成项只看 [当前交接](../00_项目管理/交接说明_current.md)；本文件不声明已取得实测数据。仓库中的示例参数均为合成输入，不能直接改称装置参数。

首轮目标是检验**固定支点、无滑移结点、无接触、保持张紧**条件下的结点与摆球运动，先比较频率、相位和位置误差。以数值已解析的工况开始，再依据残差决定是否研究失张、复杂材料或接触。高保真后端尚未取得的资格不由这一轮前向模型测试代替。

## 1. 开始采集前需要实测的输入

| 输入 | 记录方法与用途 | 对应模型 |
| --- | --- | --- |
| 装置拓扑与照片 | 确认三段独立材料绳、结点无滑移；标出 A、B、J、摆球质心及固定连接件 | 全部 |
| 支点位置与坐标系 | 用米记录三维 A、B 和测量不确定度；`e_z` 是重力方向的单位向量。记录支架运动；不等高或运动支点只进入支持该输入的柔索模型 | 全部 |
| 摆球和结点质量 | 分别记录 kg、秤分辨率、重复测量；结点质量包括随结点运动的连接件，不能重复计入绳质量 | 柔索、J3；环面要求结点惯性影响足够小 |
| 三支长度 | 区分无载参考长度、受载弧长、受载端点弦长；保持力和挂载条件一并记录。定长模型所用长度需按受载映射说明 | 全部 |
| 绳线密度与轴向响应 | 独立称重/长度测量、静态力—伸长曲线；记录可用伸长率范围。黏性或阻力参数从独立标定获得，不逐条留出轨迹重调 | 柔索 |
| 释放初态和力历程 | 释放前拍到 J、摆球和绳形，声明静止假设或初速度估计窗；记录保持位置、开始时刻、持续时间与可辨识的撤力方式 | 全部；有限时间保持力协议按正式配置能力使用 |
| 相机与时间基准 | 保存帧时间/帧率、掉帧信息、曝光、内外参、畸变及标定板尺度；运动范围在标定有效域内 | 所有视频观测 |

如果只有一台相机，优先用已标定的相机观测方程直接比较二维像素时序。仅凭单视角二维轨迹不能声称恢复了任意三维绳形或全部 J3 初态；深度初态需要额外几何约束、第二视角或独立测量。正交投影是明确的观测近似，不能默认代替透视相机。

相机采样和曝光必须能分辨**计划测量的最高频率**，尤其是结点快模态与释放瞬态。先用数值频率及短片检查时间分辨率，再保存采样/曝光选择依据；采样不足的模态只记为未解析。仿真输出间隔、实际积分步长与相机帧率分别记录。

## 2. 最小实验批次与数据划分

1. **装置与观测标定批次。** 获取几何、质量、绳材曲线和相机标定；用单独的小振幅衰减/释放记录估计确实需要的耗散与释放参数。说明哪些量实测、哪些量拟合、哪些过程尚无法辨识。
2. **小振幅留出批次。** 使用未参与拟合的释放记录，检验主频、累计相位、J/摆球位置或像素误差。首轮每个工况建议至少三次独立释放，用于观察重复性；这只是采集起点，不构成足够统计功效的保证。
3. **适用范围留出批次。** 选择一个较大但保持张紧的振幅，或一个独立测得的结点质量条件，检验三模型差异。幅度与观察窗在查看结果之前保存。先完成前两项再扩展，保留所有未按预期运行的重复。

按独立释放/工况划分标定与留出，不把同一段视频相邻帧随机分给两组。两组共用的质量、尺度或相机标定误差也具有相关性，需要保留其来源。若已用某条留出记录调整参数或选择模型，该记录转为开发数据，另采新的留出批次。

## 3. 看留出结果之前固定的预测约定

- **输入与版本：** 保存参数、初态提取方法、模型 ID、理论哈希、源码 commit、数值设置和观测标定；正式配置通过输入检查后生成预测，保留未修改的配置快照。
- **初态与时间零点：** 预先声明释放前/释放附近用于识别初态的有限窗口；其后为预测窗。不得用完整留出轨迹反推最佳初速度、相位、释放时刻或阻尼后仍称盲预测。
- **数值误差：** 对实际输入重新检查时间步、柔索网格和事件位置；合成算例的误差不自动转移到新的装置参数。数值误差预算应小于本轮想分辨的物理差异，并与测量不确定度分栏。
- **观测指标：** 预先选择 J/摆球的有效像素或三维位置误差、模态频率和整个预测窗累计相位；声明拟合方法、可辨识周期数、遮挡/缺帧处理及停止时间。只有图样相似不能代替时序比较。
- **实验判据：** 根据标定不确定度和研究问题制定误差界；任务单的合成软件阈值不充当实验精度目标。判据未固定时可采探索数据，但不能把结果包装为预先规定的盲验证。
- **越界处理：** 接触、结点滑移、支架反馈、材料越界或定长模型失张时，标记首次证据与有效终点。没有对应物理模型的后续轨迹不用于支持该模型的预测资格。

## 4. 原始记录与恢复

有真实数据时再建立 `原始/`、`派生/`、`标定/`、`留出/`。每个批次保存日期、装置照片、工况 ID、单位/坐标、原始视频与逐帧时间、参数来源和重复编号。原始文件只追加；轨迹提取、畸变校正和异常标记通过有版本的转换程序生成派生文件。

大文件可以在明确的外部存储中保留，但仓库索引必须记录可恢复位置、SHA-256、字节数、用途和获取方式。仅有 CSV 手工摘录或过期 CI 附件不能替代原始证据。

实验前暂停时应已经具备：可运行的正式入口、绑定版本的独立软件/数值证据、已知适用边界、本文输入清单，以及 current 中明确的恢复任务。暂停不表示装置标定、留出预测或全部高保真问题已完成。恢复时先提供实际装置与标定材料，再生成对应配置、做参数范围内的小规模收敛检查并冻结首轮预测。
