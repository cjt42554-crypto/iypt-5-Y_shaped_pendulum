# 装置参数与材料测量登记协议

## 1. 登记原则

所有数值以 SI 存储；展示层可另外显示 mm、g 等。原始重复必须全部保存，不能只保存平均值。任何 `MEASURED` 记录都必须绑定原始文件 SHA-256；没有原始记录时只能使用 `UNSET_REQUIRES_HUMAN`。

每条记录至少包含：

- `measurement_id`、`apparatus_revision`、`component_id` 和 `quantity`；
- `raw_repeats`、`unit` 和 `operational_definition`；
- `instrument_id`、`calibration_ref` 和时间戳；
- 温度、湿度、气压等环境状态；
- Type A、Type B 和合成标准不确定度；
- 协方差组、来源类型、原始文件哈希；
- 派生量的公式、输入 measurement IDs 和源哈希。

## 2. 来源类型

| 类型 | 合法用途 |
|---|---|
| `MEASURED` | 已有真实原始记录和哈希的直接量 |
| `DERIVED_FROM_MEASURED` | 由实测量按公开公式派生 |
| `THEORY_DESIGN_CENTER` | 无量纲理论设计中心，不是制造值 |
| `ASSUMPTION_SENSITIVITY_ONLY` | 只用于敏感性分析的假设 |
| `UNSET_REQUIRES_HUMAN` | 等待人工测量 |

模板不得把理想图谱的 `eta_numeric`、`tuned_eta` 或类似字段标为制造值或实测值。

## 3. 最低参数登记

| 参数 | SI 单位 | 操作定义 | 最低重复 |
|---|---:|---|---:|
| 支点 $\mathbf A,\mathbf B$ 三维坐标 | m | 实际约束眼或挂点的力学中心，统一世界坐标；每次装夹前后测量 | 各 3 次 |
| A、B、lower 三支无载长度 | m | 记录低预载阈值，或由力--伸长曲线外推到零力截距 | 每支 5 次 |
| 中央结点质量 | kg | 包含随动紧固件，不含固定支架 | 5 次 |
| 摆球总质量 | kg | 包含实际运行时连接附件 | 5 次 |
| 摆球几何和体积 | m、m$^3$ | 至少三个方向并声明几何模型 | 每方向 3 次 |
| 摆球 COM 到连接点矢量 | m | 固定 bob body frame 中定义，装拆前后复核 | 各 3 次 |
| bob 安装姿态参考 | rad/rotation | bob frame 与 fiducial frame 的固定关系 | 每次装配 |
| 三主惯量 | kg m$^2$ | 实测或可追溯估计，附方法与协方差 | 一次完整测定 |
| 三支线密度 | kg/m | 同材料批次独立样段，排除附件质量 | 每支或批次 3 段 |
| 三支直径 | m | 每支至少 5 个轴向位置、每点两个正交方向，记录测径预压力 | 每支 10 读数 |
| 力--伸长原始曲线 | N、m | 从松弛跨过工作载荷区，保留原始时间序列 | 5 个加卸载循环 |
| 速率依赖 | N、m、s | 至少两个慢加载速率 | 每速率 5 循环 |
| 零力死区或预张力 | N、m | 从原始曲线推导，不人工指定 | 随材料循环 |
| 滞回面积 | J | 每循环积分并扣除零漂 | 每速率 5 次 |
| 温度、湿度、气压 | $^\circ$C、%、Pa | 每批次开始和结束 | 各 1 次 |
| 支架或支点静态基准 | m | support fiducial 静止位置 | 每批次 |

## 4. 不确定度

Type A 由重复统计计算。Type B 单独记录仪器分辨率、校准证书和采用的分布假设。只有在确认无相关性时才使用：

$$
u_c=\sqrt{u_A^2+u_B^2}.
$$

存在相关量时必须使用完整协方差传播。扩展不确定度必须记录 coverage factor 及其理由，禁止默认隐藏使用 $k=2$。

## 5. 版本与失败关闭

每次机械改装、重新装夹或几何调整都生成新的 `apparatus_revision`，不得覆盖旧记录。字段缺失、单位不合格、未知键、`MEASURED` 无原始哈希或派生量无输入绑定时，schema/validator 必须失败关闭。
