# RC1 高保真模拟器状态说明草案

> 候选草案；尚未写入正式 RC1 目录。

## 当前状态

`Y-Pendulum-Simulator-v1.0.0-rc1` 作为历史参考与回滚后端冻结。

正式高保真总状态为：

`HF_NUMERICAL_QUALIFICATION_NO_GO`

该状态意味着：

- RC1 不是已经获得空间、时间和连续守卫资格的高保真求解器；
- 单条成功或完成的短轨迹不能代表空间收敛、接触后动力学、装置级物理或实验验证；
- 0.12 s 保存轨迹只能作为来源受限的归档候选工件；
- 历史空间运行的外层源码端点探针存在已记录限制；
- 不再向 RC1 直接追加新物理、接触功能或结果驱动修补。

## 允许用途

RC1 可继续用于：

1. 复核历史归档工件与来源；
2. 回滚比较和接口兼容性检查；
3. 读取既有配置、输出 schema 与历史数值行为；
4. 在明确标注未资格状态时，为实验设计提供机制假设来源。

这些用途都不能把 RC1 提升为正式数值资格。

## 禁止解释

不得以 RC1 的单条成功轨迹声称：

- 已证明三支杆或索在真实装置中的压缩、失张或接触；
- 已获得空间收敛、连续守卫或接触后动力学资格；
- 已验证锁频、分岔、混沌、长期闭合或制造参数；
- 已与实验一致；
- 已被 HF-v2 无接触静态参考包替换或升级。

## 后续修改门

RC1 默认只读。任何功能变化必须由用户单独授权，并建立新的模型身份、版本化协议和独立验证计划；不得把修改继续记在 RC1 身份下。工程性只读 CI 可以检查安装、导入、既有测试和工件解析，但 CI PASS 不能替代数值或实验资格。
