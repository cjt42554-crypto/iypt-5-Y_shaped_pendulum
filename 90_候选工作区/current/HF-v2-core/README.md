# HF-v2 纯物理核候选实现

本目录是模型 `HFV2-DISCRETE-CORD-RIGID-BOB-0.1-CANDIDATE` 的独立候选包。它与正式 RC1 后端并行存在，不修改或替代 `HF-DISCRETE-ROD-RIGID-BOB-1.0`。

本轮范围严格限于 P0/P1：冻结 RC1 基线并实现可独立审计的局部物理函数。这里没有静态求解器、时间积分器、接触求解器、公共 API 适配、HDF5、UI 或正式资格认证。

## 模型边界

- 轴向材料是只传递拉力的单边 Kelvin--Voigt 材料；压缩段的最终轴力严格为零。
- 弯曲项采用三点离散杆能量，并由解析负梯度给出节点力。
- 摆球姿态由 `SO(3)` 指数映射和群乘法推进，不用逐步归一化制造合法姿态。
- 刚体连接点、连接点速度以及力和力矩映射使用同一组几何关系。
- 质量、重力、浮力和显式启用的各向同性空气阻力均为无 I/O 的纯物理接口。
- 静态接触和动态接触均未实现；动态接触仍是 `CLOSED_PENDING_PRO_REVIEW`。

## 坐标与单位

所有数组使用 SI 数值和右手世界坐标。旋转矩阵把体坐标向量映射到世界坐标。候选状态登记体坐标角速度，因此群更新为右乘；需要连接点速度时先把角速度映射到世界坐标。

## 本地验证入口

在本目录运行：

```bash
python -m pytest
```

该命令只证明本候选包绑定的 P0/P1 实现级检查。它不证明静态或动力学数值资格，不证明三锚点结果，也不构成物理或实验验证。
