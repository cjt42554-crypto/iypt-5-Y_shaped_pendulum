## 2. 单一完整组装身份

G2R 采用 Pro 允许的“单一完整身份”设计。现有 `layout_token` 的兼容字段名保留，但语义改为坐标解释与物理组装的联合 SHA-256 身份。token 至少绑定：

- 节点 ID、节点种类、明确的摆球连接节点、自由节点顺序；
- 材料段 ID、支路、起止节点、材料坐标、段顺序；
- 自由节点、摆球平移和摆球旋转的坐标切片及广义维数；
- 参考摆球姿态和右乘 `SO(3)` 指数旋转图约定；
- 旋转图范数上限；
- 规定节点身份和规定支点位置；
- 支路材料、节点集总质量、排液体积和显式节点贡献；
- 摆球质量、体积、惯量和体坐标连接臂；
- 重力、流体密度和浮力开关。

`StaticCoordinates` 默认只能被生成它的完整物理组装接受。G2R 不增加跨环境复用或重绑定接口。

真实跨组装反例至少分别改变参考姿态、摆球连接/规定节点身份、支点位置和重力。每一例必须产生不同 token，且原组装坐标进入变体组装时失败关闭。

## 3. BFGS 实际选项

唯一求解器仍为 SciPy `minimize(method="BFGS")`。调用必须显式传入且测试实际捕获以下 `options`：

```text
gtol = 1e-9
maxiter = 2500
xrtol = 0
norm = inf
disp = false
c1 = 1e-4
c2 = 0.9
```

不增加重启、替代求解器、追加种子或容差放宽路径。优化器 `success` 仍只记录，不作为通过门。

## 4. 完整材料中心线趋势

对三条支路分别使用归一化公共材料坐标

$$
u_j=\frac{j}{128},\qquad j=0,1,\ldots,128.
$$

每层解都在本层拓扑的材料弧长坐标上作分段线性插值，共 129 个含端点样本。对每一支路和全系统报告 2→4、4→8 的最大同材料坐标点位欧氏距离，以及后一差值与前一差值之比。通过要求是每条支路和全系统的 4→8 差值均小于 2→4 差值，且比值不大于既有趋势上限 `0.95`。该审计不进入势能、广义力、求解路径或候选选择。

## 5. 无量纲段诊断

对每个选中解逐段报告下列量的最小值、最大值和数组：

$$
\varepsilon_e=\frac{\ell_e-\ell_e^0}{\ell_e^0},
$$

$$
\eta_e=\frac{\ell_e-\ell_e^0}{\ell_e},
$$

$$
\lambda_e=\frac{\ell_e}{\ell_e^0}.
$$

其中依次称为工程应变、当前长度中的伸长占比和当前长/静长比。诊断必须有限并满足恒等式 $\eta_e=\varepsilon_e/(1+\varepsilon_e)$ 与 $\lambda_e=1+\varepsilon_e$；它们不替换或放宽既有绝对伸长、张力和段长门。
