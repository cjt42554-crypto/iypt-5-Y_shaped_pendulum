## P1 方程与实现

- `topology.py` 显式登记材料节点、材料段、分支材料坐标和自由度映射；共享 Y 结点只登记一次。
- `constitutive/axial.py` 直接实现单边 Kelvin--Voigt 方程。压缩段不组装负轴力；试算力只作为审计输出。
- `constitutive/bending.py` 从 RC1 逐方程提取三点切向差弯曲能，并独立验证解析负梯度。折返反平行和塌缩段失败关闭。
- `rigid/rotation.py` 使用指数映射和群乘法；小角分支是 Rodrigues 系数的解析级数，不是备用算法。没有归一化、SVD 投影或姿态裁剪。
- `rigid/attachment.py` 使用同一旋转和连接臂计算连接点位置、速度、端点力和摆球力矩。
- `mass.py` 与 `loads.py` 提供正质量、刚体惯量、重力、浮力和显式启用的被动空气阻力接口。
- `audit/**` 位于物理模块的下游；物理模块不导入审计、验证、I/O、分析或 UI。

没有新增求解器、自动算法瀑布、随机重启、容差放宽、状态裁剪、接触、摩擦或恢复系数。

## G1 实际证据

完整数值记录见 `g1_metrics.json`。关键结果如下：

- 完整测试：42 通过，0 失败，0 跳过。
- 轴向力—能量中心差分最终相对误差：`1.20e-10`，门限 `5e-7`。
- 弯曲力—能量中心差分最终相对误差：平面 `2.75e-11`、三维 `7.15e-11`、近反平行但合法 `2.37e-8`，均通过 `5e-7` 门；误差在舍入主导前随步长下降。
- 弯曲内力尺度化合力与合矩：`6.04e-17`、`6.33e-17`。
- 刚体连接局部作用—反作用：合力范数 `0`，关于任意原点的合矩范数 `2.57e-16`。
- 弯曲共同旋转/平移客观性：相对能量变化 `1.36e-16`，力协变相对误差 `1.23e-15`；轴向和连接点客观性案例也通过。
- 压缩段最终张力严格为 `0.0`；活动黏性耗散率 `0.4`，投影卸载耗散率 `20.0`，均非负；功率平衡残差不大于 `1.67e-16`。
- 10000 次群更新后姿态正交误差 `5.72e-13`、行列式误差 `1.68e-13`，通过 `2e-12` 门。
- 架构审计：禁用依赖 0、求解器依赖 0、物理核心 `try` 语句 0、随机调用 0、静默 fallback 0。
- 直杆零弯曲能/力、光滑圆弧网格加密趋势、精确反平行与塌缩几何失败关闭均通过。
