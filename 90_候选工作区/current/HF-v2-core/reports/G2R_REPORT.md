## 2. 预冻结、偏离与运行时附录

G2R 原协议在任何 G2R 目标运行前以本地提交 `7a19702` 冻结，固定了完整身份语义、129 点中心线规则、无量纲诊断和历史等价性容差。原 G2 的两项后验修正已经版本化披露：

1. `g2_module_manifest.json` 中 `physical_core` 允许依赖从仅自身扩展到状态和拓扑合同；
2. 第一次未提交 G2 目标试算后，闭合审计才被修正为区分平衡残差与作用—反作用恒等式残差。

两项修正数学和工程理由成立，但确实发生在原 G2 目标结果被观察之后。因此历史 G2 工件只作为修正后可信证据，不再描述为完整无偏预注册结果。

第一次 G2R 尝试又发现历史 SciPy 1.11.4 不接受 BFGS 的 `c1`、`c2` 选项，并连续发出 `Unknown solver options`。该临时运行整体作废，未提交其 JSON，也未据其数值改变任何门。随后在本地提交 `8adc7f5` 中冻结 G2R-A1 运行时附录：最低 SciPy 修正为 1.12、未知选项失败关闭、第一次有效运行绑定 CPython 3.12.3、NumPy 2.5.2 和 SciPy 1.18.1。SciPy 1.12 的官方 BFGS 文档明确列出 `c1` 和 `c2` 选项：<https://docs.scipy.org/doc/scipy-1.12.0/reference/optimize.minimize-bfgs.html>。

G2R-A1 没有改变原 G2R 的物理门、中心线门或等价容差。后续第一次有效运行没有未知选项警告，并通过原门。

## 4. BFGS 冻结参数实际生效

生产调用使用的实际 options 映射为：

```text

maxiter = 2500
xrtol = 0
norm = inf
disp = false
c1 = 1e-4
c2 = 0.9
```

单元测试替换 SciPy 入口并捕获实际参数，确认七项全部进入调用。G2R 证据还检查当前 `_minimize_bfgs` 实现签名确实包含 `c1` 和 `c2`。生产入口将未知求解器选项警告提升为异常，防止以后版本或不兼容环境静默忽略冻结参数。

求解器仍只有 BFGS；没有增加重启、替代求解器、追加随机种子或容差放宽。
