## 3. 下一次 Codex 的唯一范围：P2

P2 只实现**无接触静态制备**。不得进入 P3、P4 或以后阶段。

P2 必须完成：

1. 建立绑定拓扑、自由节点布局、质量布局、材料段顺序和广义坐标切片的静态组装对象；
2. 所有局部轴向和弯曲静长只由拓扑材料坐标生成，不接受第二套独立静长输入；
3. 在目标结果出现前冻结节点质量集总、规定支点端、共享结点和刚体连接点端的质量处理；
4. 组装轴向、弯曲、重力、浮力和刚体连接的总势能；
5. 实现总势能的解析广义力，并用独立有限差分验证，包括摆球旋转切空间方向；
6. 在看到目标结果前冻结一个主求解算法、容差、确定性多种子集合和选择规则；
7. 先通过解析或高精度可控小系统，再运行一个明确无接触、正净空的 Y 形锚点；
8. 独立复算力平衡、反力、单边轴力、方程域裕量、局部极小性和至少三层静态网格趋势；
9. 生成 P2/G2 清单、报告和可复算机器证据；
10. 更新交接，提交到 `main` 后停止，交回 Pro 审查。

## 4. P2 设计约束

- HF-v2 物理模型身份保持 `HFV2-DISCRETE-CORD-RIGID-BOB-0.2-CANDIDATE`；静态算法使用单独的 solver/contract 身份。
- 静态速度为零，不把黏性项伪装成静态力。
- 质量离散默认采用每段参考质量对两端各分配一半的节点集总规则；若采用其他规则，必须在目标运行前给出方程和网格极限理由。
- 状态、质量和拓扑的布局验证必须由组装器强制执行，不能只提供可选的 `validate_*` 方法后依赖调用者。
- 净空在 P2 只作解后模型域审计。非正净空解是 P2 域外结果，不得产生接触反力或罚势。
- 首个 Y 形锚点必须严格位于张紧、非塌缩、非折返和正净空的光滑内部域；各最小裕量在目标结果出现前冻结。
- P2 新增模块必须进入自动发现清单；架构审计应规范化相对导入并按分类依赖矩阵拒绝核心反向依赖，不能通过把文件标成 `audit` 绕过扫描。
- RC1 只作共同模型域表征，不是 HF-v2 静态真值。
- 优化器退出码不能代替广义力残差、二阶稳定性和多种子选择审计。

## 5. 禁止事项

P2 期间不得：

- 修改正式 `01_最终理论/**`、`02_模拟程序/**`、顶层 `AGENTS.md`、UI、公共 API 或 HDF5；
- 接入静态或动态接触、冲量、摩擦、恢复系数或罚刚度；
- 使用 `compression_regularization_scale`；
- 运行 `alpha=1e-2/1e-4/1e-6` 接触压缩目标；
- 自动换优化器、结果驱动放宽门槛、追加随机种子或裁剪状态；
- 复制 RC1 的静态求解器单体和 fallback 链；
- 因旧测试期望而恢复 `0.1` 弯曲方程；
- 自动继续 P3。

## 6. G2 停止规则

完成 P2 后必须停止。G2 最低证据见 `06_PRO_G1R_REVIEW_AND_P2_GATE.md`，至少包括：

- 总势能—广义力一致性；
- 布局和质量组装一致性；
- 解析小系统；
- 单边静态轴力及首个锚点的严格张紧裕量；
- 正净空锚点；
- 独立二阶稳定性；
- 冻结多种子；
- 三层静态网格趋势；
- 单一命令可复算证据。

G2 不构成动力学、接触、三锚点完整资格或实验验证。完成后提交并等待 Pro 与用户的新裁决。
