## 3. 下一次唯一范围：P3 静态硬接触

P3 只实现静态、无摩擦、刚性、单边法向接触。任何目标接触结果出现前，必须先提交并冻结：

1. 新的 HF-v2 接触模型身份和接触组装身份；
2. 正式只读接触登记到逐约束集合的映射合同；
3. `full_pairs`、`partial_pairs`、结点套筒和摆球套筒活动域的逐项身份；
4. 每项接触的固定参数域、最近点见证、间隙 $g_i$、法向和雅可比 $J_{g_i}$；
5. 非唯一最近点、零距离法向、塌缩段、重复约束和活动集秩亏的失败关闭政策；
6. 唯一主静态接触求解算法、确定性多种子、容差和选择规则；
7. 原始可行性、对偶可行性、平衡、互补和二阶稳定性门；
8. 小型解析或高精度接触基准；
9. 首个目标静态接触算例和 G3 停止规则。

应先做几何与 KKT 单元基准，再运行一个目标静态接触算例。不得先看目标结果再选择接触域、算法或阈值。

## 4. P3 实现原则

- P2 的轴向、弯曲、刚体、质量和无接触静态方程保持冻结；接触以新的约束层加入。
- 静态接触和无接触静态共享同一物理核心、坐标组装和材料身份。
- 每项接触必须有独立身份；全局最小净空只能用于汇总，不能代替约束集合。
- 优化器自身的 `success` 不能代替 KKT 和二阶审计。
- 非光滑或退化情形必须失败关闭，不能任取法向或静默删约束。
- 新的接触身份必须绑定接触登记版本、接触对身份、参数域、所需中心距、接触政策和模型版本。

## 5. 禁止事项

P3 不得：

- 直接复制或导入已退出工作树的旧 `hard_contact_candidate`；
- 把旧 RC1 guard、压缩扫描或旧接触候选结果写成 HF-v2 证据；
- 使用罚刚度、柔顺接触或无依据的接触势；
- 实现摩擦、恢复系数、冲量、动态互补或接触后时间积分；
- 增加求解器 fallback、失败后随机重启、容差放宽或结果驱动的新种子；
- 修改 P2 方程以制造接触可行性；
- 修改正式 `01_最终理论/**`、`02_模拟程序/**`、顶层 `AGENTS.md`、UI、公共 API 或 HDF5。

## 6. G3 停止门

P3 完成后必须停止并交回 Pro。至少交付：

- 接触身份、逐约束登记和预冻结协议；
- 小型基准和目标静态接触结果；
- 间隙与雅可比独立复算；
- KKT、互补、乘子符号和二阶稳定性证据；
- 多种子、约束身份和退化情形审计；
- 与 P2 无接触域的兼容性回归；
- 全部测试、静态检查和单命令证据；
- current/history 交接。

即使 G3 候选通过，也不得自动进入 P4、P5 或 P6。动态接触仍需新的 Pro 裁决和用户明确指令。
