# HF-v2 分阶段实施计划

## 总体策略

HF-v2 与 RC1 并行开发。每一阶段只解决一个层次的问题，并在进入下一阶段前形成可独立否证的门。禁止一次性重写整个程序后再集中调试。

## P0：基线冻结与候选骨架

状态：已完成。

完成内容包括 RC1 源码身份、公共接口、依赖图、候选包骨架和局部无接触表征。RC1 保持只读参考，不作为绝对真值。

## P1：纯物理核

状态：实现级测试已通过，提交为 `4d8777095e90f431d686ae338b754abb430a6a98`。

已实现显式拓扑、单边轴向材料、旧 `0.1` 三点弯曲能、质量与外载、`SO(3)` 运算、偏心连接和局部审计。Pro 审查认可工程范围和多数局部公式，但不批准由此直接进入 P2。

## G1R：Pro 审查修正阶段

### 目标

在任何静态求解器出现前，修复 G1 独立审查发现的模型合同和证据链缺陷。

### 工作

1. 模型身份升级为 `HFV2-DISCRETE-CORD-RIGID-BOB-0.2-CANDIDATE`；
2. 用离散曲率二次能替换切向差弯曲能，并实现解析力；
3. 将参考静长定义为材料弧长坐标差，删除双重真值；
4. 将状态与节点质量绑定明确的自由节点布局；
5. 自动发现并分类全部候选源码模块；
6. 由单一确定性命令生成清单驱动的 G1R 数值证据；
7. 修正刚体惯量可实现性、动量有限性和 `SO(3)` 容差一致性；
8. 保留 `0.1` G1 报告作为历史工件，新建 `0.2` G1R 报告。

### G1R 门

完整要求见 `05_PRO_G1_REVIEW_AND_G1R.md`。至少包括：

- 新弯曲力—能量解析一致性；
- 折返能垒随 $\theta\to\pi$ 发散；
- 客观性、合力合矩、直杆和圆弧加密继续通过；
- 材料参考弧长唯一；
- 状态/质量布局错配失败关闭；
- 证据可由单一命令复算；
- 全部测试与静态检查通过；
- 正式目录无变化。

完成后必须停止并交回 Pro。不得自动进入 P2。

## P2：无接触静态制备

状态：`HOLD_PENDING_G1R_PRO_APPROVAL`

### 进入条件

- G1R 完成；
- Pro 再次审查批准；
- 用户明确要求继续。

### 目标

直接求解 HF-v2 `0.2` 张力单边模型的定端静态平衡，不使用 `compression_regularization_scale`。

### 工作

1. 组装总势能和固定端点约束；
2. 预冻结一个主求解算法，不建立自动求解器瀑布；
3. 预冻结确定性多种子协议；
4. 独立复算力平衡和二阶稳定性；
5. 先做解析小系统，再做一个无接触、正净空锚点算例。

### G2

- 力残差通过冻结门；
- 单边轴力成立；
- 局部极小性有独立证据；
- 多种子规则不使用目标结果调参；
- 静态形状和反力具有网格趋势。

## P3：静态硬接触

### 目标

把逐接触反力纳入静态方程，消除事后净空判定。

### 工作

精确适配正式 `full_pairs`、`partial_pairs`、结点/摆球套筒活动域，组装每项 $g_i$ 和 $J_{g_i}$，求解并独立审计 KKT 与二阶条件。

### G3：Pro 裁决门

Codex 提交证据后停止。Pro 裁决接触登记、KKT 与稳定性是否允许进入动力学。

## P4：平滑区间动力学

实现统一隐式中点、群姿态、单一 Newton/线搜索、预冻结步长控制和完整功率账本。必须验证二阶时间收敛、保守能量阶数、被动耗散和对称基准动量。

## P5：张紧—松弛活动集

实现半光滑活动集或等价互补推进，使每个接受步直接满足非负轴力。完成后进入 Pro 裁决门。

## P6：动态硬接触

状态：`CLOSED_PENDING_PRO_REVIEW`

开启前必须由 Pro 冻结速度/位置互补、冲量律、恢复系数、摩擦、接触集和能量动量合同。Codex 不得自行使用罚刚度或库默认值。

## P7：外围适配

核心通过后接入现有配置、公共 API、结果、HDF5、分析和 UI。适配器只转换数据，不复制物理；RC1 与 HF-v2 并行存在。

## P8：性能、三锚点与正式提升

完成空间/时间加密、模型形态比较和剖析后优化。只有用户明确授权且 Pro 通过审查，才能修改正式 `02_模拟程序/**`。RC1 在代表性验证完成前不得删除。
