# HF-v2 分阶段实施计划

## 总体策略

HF-v2 与 RC1 并行开发。每一阶段只解决一个层次的问题，并在进入下一阶段前形成可独立否证的门。禁止一次性重写整个程序后再集中调试。

状态：已完成。

完成内容包括 RC1 源码身份、公共接口、依赖图、候选包骨架和局部无接触表征。RC1 保持只读参考，不作为绝对真值。

### 已完成并获实质认可的内容

- 拓扑、状态、质量、材料段和广义切片的静态组装；
- 参考静长只从材料坐标生成；
- 端点质量/排液体积集总；
- 单边轴向、离散弯曲、重力、浮力和偏心刚体连接总势能；
- 解析广义力和右 Jacobian 转矩映射；
- 单一 BFGS、三个确定性种子；
- 解析竖直系统、严格正净空 Y 锚点；

- 相对导入规范化和分类依赖矩阵。

### 阻断 G2 的问题

1. `layout_token` 没有绑定节点种类/附件节点、参考姿态、支点位置、环境和旋转图域，真实不同组装可能发生 token 碰撞；
2. 预冻结后的模块依赖清单被修改，且第一次目标试算后修正了闭合审计定义，协议偏离没有完整版本化；
3. 冻结的 BFGS `c1`、`c2` 没有显式传给 SciPy；
4. 三网格形状趋势只覆盖结点、附件和摆球，没有覆盖完整材料中心线。

完整复审见 `07_PRO_G2_REVIEW_AND_G2R.md`。

## G2R：G2 复审修正阶段

状态：`REQUIRED_BEFORE_G2_APPROVAL`。

### 目标

在不改变 P2 物理方程、目标算例和既有数值门的前提下，修正身份绑定和证据治理缺陷，并补齐完整材料中心线趋势。

### 工作

1. 建立字段完备的坐标布局身份和完整物理组装身份，或将全部必要字段纳入单一 token；
2. 增加真实跨组装碰撞测试；
3. 显式传入 BFGS `c1=1e-4`、`c2=0.9`；
4. 保留当前 G2 工件，版本化披露预冻结模块清单变化和后验闭合审计修正；
5. 在固定公共材料坐标网格上比较三条支路完整中心线；
6. 增加最小应变、伸长比和当前长/静长比诊断；
7. 用不变的物理参数、Y 锚点、种子、网格、求解器和阈值重新生成证据；
8. 比较修正前后能量、宏观形状、张力、反力和稳定性；
9. 完成全部测试、静态检查和交接。

### G2R 门

- 不同参考姿态、附件节点、支点位置或环境的组装不能静默共享坐标；
- 身份字段和语义完整；
- BFGS 实际调用接收全部冻结参数；
- 协议偏离有版本、哈希和时间顺序；
- 三条支路完整中心线的 2→4、4→8 差值均缩小；
- 修正前后主要静态观测量等价；
- 当前 G2 历史工件保持不变；
- 正式目录无变化。

完成后必须停止并交回 Pro，不得自动进入 P3。

## P3：静态硬接触

状态：`CLOSED_PENDING_G2R_PRO_APPROVAL_AND_NEW_USER_INSTRUCTION`。

### 目标

把逐接触反力纳入静态方程，消除事后净空判定。

### 工作

精确适配正式 `full_pairs`、`partial_pairs`、结点/摆球套筒活动域，组装每项 $g_i$ 和 $J_{g_i}$，求解并独立审计 KKT 与二阶条件。

### G3：Pro 裁决门

Codex 提交证据后停止。Pro 裁决接触登记、KKT 与稳定性是否允许进入动力学。

## P4：平滑区间动力学

实现统一隐式中点、群姿态、单一 Newton/线搜索、预冻结步长控制和完整功率账本。必须验证二阶时间收敛、保守能量阶数、被动耗散和对称基准动量。

## P5：张紧—松弛活动集

实现半光滑活动集或等价互补推进，使每个接受步直接满足非负轴力。完成后进入 Pro 裁决门。

## P6：动态硬接触

状态：`CLOSED_PENDING_PRO_REVIEW`

开启前必须由 Pro 冻结速度/位置互补、冲量律、恢复系数、摩擦、接触集和能量动量合同。Codex 不得自行使用罚刚度或库默认值。

## P7：外围适配

核心通过后接入现有配置、公共 API、结果、HDF5、分析和 UI。适配器只转换数据，不复制物理；RC1 与 HF-v2 并行存在。

## P8：性能、三锚点与正式提升

完成空间/时间加密、模型形态比较和剖析后优化。只有用户明确授权且 Pro 通过审查，才能修改正式 `02_模拟程序/**`。RC1 在代表性验证完成前不得删除。
