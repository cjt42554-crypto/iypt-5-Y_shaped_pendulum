## 2. 新弯曲方程复核

令

$$
d=t_{i,-}\cdot t_{i,+},
\qquad
\boldsymbol\kappa_i=
\frac{2t_{i,-}\times t_{i,+}}{1+d}.
$$

由单位切向条件可得

$$
\left\lVert\boldsymbol\kappa_i\right\rVert^2
=
\frac{4(1-d)}{1+d},
$$

因此当前实现的局部能量等价于

$$
U_i=
\frac{2EI_i}{\bar\ell_i}
\frac{1-d}{1+d}.
$$

其对 $d$ 的导数为

$$
\frac{\partial U_i}{\partial d}
=
-\frac{4EI_i}
{\bar\ell_i(1+d)^2}.
$$

提交中的 `energy_derivative_dot` 与此完全一致；再结合单位切向对左右段向量的导数，节点力装配的三个符号也与 $-\nabla_x U_i$ 一致。未发现因左右段、节点索引或负梯度转换造成的符号错误。

当转角 $\theta=\pi-\varepsilon$ 且 $\varepsilon\to0^+$ 时，

$$
U_i
\sim
\frac{8EI_i}
{\bar\ell_i\varepsilon^2},
$$

所以折返能垒由方程自身发散，不再是“有限能量方程加外围角度守卫”。代码只在 $1+d\le0$ 时因曲率分母失效而拒绝；没有分母裁剪或备用能量。

提交记录的四级能量和相邻比例与上述解析式相符。平面、三维和近反平行样例的最终有限差分误差均通过原 `5e-7` 门，内力合力、合矩和客观性结果与当前解析式相容。

## 3. 零刚度分支

当 $EI=0$ 时，弯曲势能恒等于零，其坐标梯度也恒等于零。因此在构造切向和反平行分母前返回零能、零力，是模型的精确数学分支，不是失败后的 fallback。

该分支不会使完整系统接受塌缩杆段：轴向材料、后续静态组装和动力学仍必须分别执行自己的几何域检查。不得把零弯曲刚度分支扩展成跳过其他物理域检查的通用例外。

## 4. 材料参考、状态与质量布局

`MaterialSegment.rest_length` 已从独立构造参数改为

$$
\ell_e^0=S_{e,\mathrm{end}}-S_{e,\mathrm{start}},
$$

消除了拓扑对象内部的双重真值。分支材料区间连续性、总参考长度和细分不变性测试满足 G1R 要求。

`HFV2State` 和 `MassProperties` 均保存不可变 `free_node_ids`，并与拓扑逐项比较；相同节点数但交换顺序的布局会失败关闭。刚体惯量的正定性和主惯量三角不等式、动量有限性以及共享 `SO(3)` 容差也已按要求实现。

上述布局合同足以进入组装阶段，但 P2 必须把验证变成组装对象的强制前置条件，不能依赖调用者自行记得调用 `validate_topology` 或 `validate_state`。

## 6. P2 的强制入口条件

G1R 通过不意味着 P2 可以任意设计。P2 必须在看到目标静态结果前冻结以下合同。

### 6.1 唯一参考长度必须延伸到组装层

局部 `AxialMaterial` 和弯曲函数仍可接收数值静长，这是纯函数接口；组装模型不得把这些数值作为第二套用户输入。

P2 必须做到：

1. 每段 $\ell_e^0$ 只从拓扑材料坐标派生；
2. $EA_e$、$EI_e$、线密度和其他材料参数按段或按支路登记，但不再次登记独立静长；
3. 轴向材料对象和弯曲静长数组只能由组装器内部从拓扑生成；
4. 组装审计逐段证明传入局部公式的静长等于材料坐标差。

### 6.2 布局绑定必须由组装器强制执行

P2 的静态系统构造器必须同时绑定：

- `HFV2Topology`；
- `free_node_ids`；
- 节点质量布局；
- 材料段顺序；
- 广义坐标切片。

所有势能、梯度、Hessian 和解向量入口都必须使用该绑定布局。不得让调用者直接传入无身份的同形数组后绕过布局核对。

### 6.3 质量离散必须预冻结

在运行目标锚点前，P2 必须明确并测试参考质量积分。默认采用每个材料段质量按参考长度计算并对两端各分配一半的标准节点集总规则；规定支点、共享结点和刚体连接点处的贡献必须分别说明：

- 规定支点端贡献只影响常量势能和支点反力；
- 共享结点累加所有入射段贡献及显式结点质量；
- 刚体连接点端贡献在静态势能中按连接点位置计入，不得无说明地并到摆球质心；
- 该规则在均匀细分下保持总质量和重力势能收敛。

若 Codex提出不同质量离散，必须在运行目标结果前给出方程和收敛理由，不得结果出来后再选择。

### 6.4 P2 仍是无接触静态阶段

P2 只允许：

- 组装无接触总势能；
- 冻结一个主求解算法和确定性多种子协议；
- 做解析或高精度可控小系统；
- 做一个明确处于正净空域内的 Y 形锚点；
- 独立复算广义力残差、局部极小性、布局、质量和单边张力；
- 进行静态网格趋势。

净空计算在 P2 只能作为解后域审计，不能产生接触反力、罚势或算法分支。任何候选解进入非正净空域，应标记为 P2 模型域外并停止，不得用接触补丁把它改造成通过。

首个 Y 形锚点还必须严格处于光滑内部域：所有材料段具有预冻结的正伸长/正张力裕量，所有当前段长和曲率分母具有正域裕量。P2 不应在第一个整机算例中同时调试松弛活动集、塌缩极限或近折返奇性。

### 6.5 架构审计随 P2 扩展

P2 新增源码后，模块自动发现仍必须零遗漏，并增加两项检查：

1. 将相对导入解析为规范包路径；
2. 按模块分类执行允许依赖矩阵，使生产求解器不能反向依赖报告、证据或 UI 层。

分类本身不能成为逃逸开关；生产职责文件不得仅通过标记为 `audit` 而免于依赖审计。

## 7. P2 禁止事项

P2 不得：

- 修改正式 `01_最终理论/**`、`02_模拟程序/**`、UI、公共 API 或 HDF5；
- 接入 `hard_contact_candidate` 作为静态反力；
- 实现 P3 接触 KKT、P4 动力学或 P5 活动集；
- 使用 `compression_regularization_scale`；
- 在主算法失败后自动换优化器、放宽容差或追加随机种子；
- 把优化器 `success` 当作力平衡或稳定性证据；
- 把 RC1 单条静态状态当作 HF-v2 真值；
- 运行 `alpha=1e-2/1e-4/1e-6` 接触压缩目标。

## 8. G2 停止门

P2 完成后必须停止并交回 Pro。G2 至少要求：

1. 组装总势能的解析广义力与独立有限差分一致；
2. 固定端点、刚体连接和材料布局无静默错配；
3. 每段静态轴力非负，且首个 Y 形锚点具有冻结门内的严格正张力/正伸长裕量；
4. 解析小系统的解、反力和稳定性符合基准；
5. 目标无接触锚点具有冻结门内的力残差、严格正净空、正段长和正曲率分母裕量；
6. 二阶稳定性由独立 Hessian/方向曲率证据支持；
7. 多种子集合和选择规则在目标结果前冻结；
8. 至少三层静态网格给出形状、反力和势能趋势；
9. 报告明确区分实现测试、静态数值资格和仍未进行的动力学/实验验证。

G2 通过后也只能声明无接触静态算法的条件性数值资格。是否进入 P3 仍需用户新指令和 Pro 再审。
