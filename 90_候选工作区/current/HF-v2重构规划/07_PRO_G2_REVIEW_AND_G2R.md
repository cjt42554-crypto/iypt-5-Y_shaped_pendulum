## 2. 已通过的实质性复核

### 2.1 总势能和广义力

静态组装包含：

- 张力单边轴向弹性能；
- 离散曲率弯曲能；
- 材料节点和连接点处的重力、浮力势；
- 摆球质心处的重力、浮力势；
- 偏心刚体连接运动学。

对参考姿态右乘指数坐标

$$
R=R_0\exp(\widehat\phi)
$$

的变分，附件体坐标力矩先形成

$$
\tau_b=a_0\times R^{\mathsf T}F_a,
$$

再由右 Jacobian 转为旋转向量坐标力

$$
Q_\phi=J_r(\phi)^{\mathsf T}\tau_b.
$$

代码中的符号和坐标系转换与该式一致。非零旋转探针的总势能中心差分也支持这一结论。

### 2.2 质量、参考长度和端点贡献

每段参考长度只由材料弧长坐标差生成；线质量和排液体积按参考长度计算并向两端各集总一半。规定支点端贡献保留在常量势能和反力中，共享结点累加入射段贡献，连接点端贡献作用在实际附件位置而不是摆球质心。该处理满足 P2 的冻结质量合同。

### 2.3 反力闭合

修正后的闭合审计区分：

1. 自由广义力是否接近平衡；
2. 内力、支点反力和外力是否满足作用—反作用恒等式。

从全局外力与支点反力中扣除尚存的自由广义残差，是检查第二项的正确做法；原始未扣除平衡残差也被保留。因此修正后的闭合定义本身是正确的，不属于为了掩盖残差而删掉失败量。

### 2.4 BFGS 状态 2

2 段和 8 段所选候选记录 SciPy 状态 2，4 段记录状态 0。当前证据没有把 `optimizer_success` 当作通过门，也没有增加重启、替代优化器或放宽容差。所有种子仍分别接受广义力、模型域、二阶稳定性和净空审计。

由于该静态问题具有绕连接臂旋转的规范零模，BFGS 精度损失并不自动等于候选平衡错误。在当前冻结协议下，状态 2 不是单独的否决理由；但它仍应保留为算法局限，不能在后续报告中改写成求解器正常成功。

### 2.5 数值结果

提交中的解析竖直小系统与闭式位置、张力、支点反力和物理 Hessian 相符。三层 Y 形结果均处在严格张紧、非塌缩、非折返和正净空域，广义力与二阶门有明显余量。提交报告的结点—附件—摆球、反力和势能相邻层差值均约按四分之一缩小。

独立复核还重建了相同总势能和 BFGS 问题；得到的平衡能量、主要形状、张力和三层趋势与提交结果一致。该复核支持“提交的静态结果不是由报告抄写错误制造”的判断，但不替代仓库中的完整测试执行。

## 3. 阻断问题 A：`layout_token` 不是完整绑定

`StaticAssembly` 和 G2 报告声称静态坐标携带由完整组装生成的确定性 token，从而阻止相同形状但身份不同的坐标进入另一组装。

实际 token 当前只纳入：

- 节点 ID 和自由节点 ID；
- 材料段、支路材料和段顺序；
- 已集总节点质量、排液体积；
- 摆球质量、体积、惯量和连接臂；
- 广义坐标维数。

它没有纳入至少以下会改变坐标解释或势能的量：

- 节点 `kind` 和明确的摆球连接节点身份；
- 参考摆球姿态 $R_0$；
- 规定支点位置；
- 重力、流体密度和浮力开关；
- 旋转图域约定与上限。

因此可以构造两个具有相同拓扑 ID、材料和质量，但参考姿态或环境不同的 `StaticAssembly`。两者会生成相同 token；来自第一个组装的 `StaticCoordinates` 会被第二个组装接受，而同一个旋转向量此时可对应不同物理姿态和不同附件位置。这是实际的静默错配，不是命名问题。

现有测试只构造了手写字符串 `alien-layout`，没有构造两个真实且 token 碰撞的组装，因此没有覆盖该反例。

### G2R 要求

采用下列两种设计之一，并明确文档语义：

1. **双身份设计**：
   - `coordinate_layout_id` 绑定所有坐标解释所需内容，包括节点种类、附件节点、自由节点顺序、段顺序、切片、参考姿态和旋转图域；
   - `assembly_model_id` 再绑定规定支点、环境、材料、质量和摆球物理；
   - 默认 `evaluate` 只接受同一 `assembly_model_id`，跨环境复用必须通过显式重绑定接口。
2. **单一完整身份设计**：把上述坐标和物理字段全部纳入现有 token。

必须增加真实碰撞测试，至少分别改变参考姿态、附件/规定节点身份、支点位置和重力，并证明跨组装坐标失败关闭。

## 4. 阻断问题 B：预冻结完整性没有成立

预冻结提交中的 `g2_module_manifest.json` 规定：

```json
"physical_core": ["physical_core"]
```

实现提交将其改为：

```json
"physical_core": ["physical_core", "state_contract", "topology_contract"]
```

这项修改有合理的工程原因：既有 `mass.py` 的类型导入需要后两类。但它仍然发生在声称“协议已冻结”的提交之后。当前 G2 证据绑定的是修改后的清单，而报告没有明确披露该预冻结文件已变化。

此外，报告披露第一次未提交目标试算因为把原始平衡残差误当作第二个闭合门而 `NO-GO`，之后才修正闭合定义。修正后的数学定义是正确的，且没有改变物理参数、种子、求解器或数值阈值；但从严格预注册角度看，它仍是看到目标结果后发生的审计定义修正。

因此，当前结果可以作为可信的**修正后证据**，但不能再描述为“所有 G2 协议和审计在目标结果前完整冻结且未变化”。

### G2R 要求

- G2R 不得改变物理方程、Y 锚点、2/4/8 网格、三个种子、BFGS 方法、既有数值门槛或选择规则；

## 5. 阻断问题 C：冻结的线搜索参数没有进入求解器调用

`StaticSolverSettings` 保存并校验 `armijo_c1=1e-4` 和 `curvature_c2=0.9`，但 `scipy.optimize.minimize` 的 `options` 中没有传入 `c1`、`c2`。当前 SciPy 版本的默认值碰巧相同，所以本次结果没有因此改变；然而包依赖只约束 `scipy>=1.11`，未来默认值变化时，清单中的“冻结参数”将不再控制实际算法。

### G2R 要求

- 在 BFGS 调用中显式传入 `c1`、`c2`；
- 增加能够捕获实际传给 SciPy 的 options 的测试；
- 不改变这两个值，不引入第二求解器或失败后重试。

## 6. 必须补齐的网格证据

当前所谓“形状趋势”只比较结点、附件和摆球三个宏观位置，没有比较三条绳的完整材料中心线。宏观端点收敛不能排除内部离散形状仍有较大差异。

G2R 必须在固定的公共材料坐标网格上，对每条支路的分段线性中心线进行重采样，并报告至少：

- 2→4 和 4→8 的最大点位差；
- 每条支路及全系统的差值；
- 后一差值与前一差值之比；
- 采样点数和材料坐标规则。

该项只增加审计，不得进入势能或求解路径。现有端点、反力和势能趋势继续保留。

## 7. 非阻断性限制

以下问题不否定当前静态结果，但后续必须保持清楚：

1. **优化器状态**：大部分 Y 候选不是 SciPy 正常成功退出。不得删除该事实；正式提升前应考虑消除静态规范自由度，而不是长期依赖状态 2 加外部认可。
2. **种子选择的舍入敏感性**：三个合格候选的势能差约为机器舍入量，按精确浮点最小值选择可能随 SciPy/平台改变。当前证据绑定了运行环境，因此不阻断本轮；正式协议应使用预冻结的能量并列容差或固定资格环境。
3. **网格客观裕量**：绝对段伸长和绝对段长随网格细分缩小，不能作为任意加密下的永久门。G2R 至少增加最小应变、伸长比和当前长/静长比作为诊断；以后网格资格应优先使用无量纲量和张力。
4. **远端 CI**：当前提交没有 GitHub 状态检查。`67 passed`、Ruff、`compileall` 和渲染检查仍是 Codex 提交携带的本地证据，不是远端 CI 背书。
