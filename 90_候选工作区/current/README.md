## 稳定约定

1. 候选理论、程序、资料和运行入口保存在 `候选实现或候选内容/`。
2. 计划、映射、验收口径和验证结果保存在 `管理/`。
3. 新审查先进入 `审查与复现/当前审查/`；被新结论取代后再移入 `历史审查/`。
4. 根目录 `01_最终理论/`、`02_模拟程序/`、`03_项目资料/` 是成熟基线。只有用户明确指定回写范围并完成相应验证时，才把候选组件写回成熟基线。
5. 任何 PASS、资格或预测声明只对其绑定的文件、提交、配置、命令和环境有效；本页不复制这些动态结论。

开始实际工作时，先读取当前候选主体的 README，再按任务读取对应管理和审查材料。
