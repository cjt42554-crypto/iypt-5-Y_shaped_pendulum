# Y 形摆：三锚点高保真初始窗数值资格

## 1. 结论

本目录把上一轮 `4:3`、`3:2`、`2:1` 三个锚点提升到正式高保真空间层级，并在同一份预冻结资格规格下完成：

- 三锚点各 3 个空间层级的准备态审计；
- 三锚点各 3 个空间层级、`0.12 s` 初始窗的动态 Cauchy 诊断；
- `3:2` 生产层的独立单束证书尝试。

三个锚点的高保真数值资格均为 **NO-GO**，不能转化为装置尺寸、加工公差或真实频率比建议：

1. 三个锚点的正式 Cauchy 门均未整体通过。`4:3` 和 `3:2` 的失败指标是最大杆速度，`2:1` 的失败指标是摆球角速度 RMS。
2. `4:3` 的轴向压缩在三层准备态和三层动态结果中都存在，且细化后没有消失；它属于双侧材料律下的准备态和后续响应，不是上一轮 1--2 单元网格的偶然假象。
3. `3:2` 在三个正式空间层级的 `0--0.12 s` 内始终严格受拉；上一轮 2 单元结果在 `t=0.025 s` 出现的负轴力没有复现。证据指向低于正式层级的空间离散或其他数值设置，但本轮没有通过单因素消融把原因唯一归给网格。
4. 三个锚点的所有准备态都因 `ROD_SELF_CLEARANCE` 低于预冻结的最小归一化裕量 `3e-4` 而失败。生产层最小值约为 `1.09e-4`、`8.38e-5` 和 `3.60e-5`。进一步分解表明，九个层级的赢家都是下支同支局部排除边界，不是跨支、接头或摆球套筒碰撞；三个原始间隙都为正。
5. `2:1` 在三个层级还同时失败于 `BOB_SOCKET_RADIAL_MONOTONICITY`，生产层为 `8.71e-5`。其原始径向点积为正、局部方向余弦也为正；失败来自局部单元点积随网格尺寸缩小，而资格门继续用全局长度平方归一化，不能解释成套筒处反向折返。
6. 最终证据复核发现，历史空间运行的外层源码探针把已经位于 `src/` 的路径又拼接了一次 `src/`，所以原始结果中的 `e3b0...` 是空 Python 源码树哈希。当前正式源码哈希 `1c0...` 与冻结计划一致，探针也已修复，但这不能倒推证明三次历史空间研究的两个运行端点。汇总状态因此明确增加 `SOURCE_ENDPOINT_PROBE_INVALID`，没有把原始 `formal_source_stable=true` 继续当成有效证据。
7. `4:3` 压缩极限研究已裁决主制备身份，并在正式目录之外构建隔离覆盖层。原定 `alpha=1e-2`、`1e-4`、`1e-6` 的定端准备态通过数为 `0/3`：所有种子的唯一非正原始守卫都是 `ROD_SELF_CLEARANCE`，其中两个更小尺度还未达到力残差门。原目标计划的动力学数保持为 0。
8. 在任何中间尺度结果出现前冻结的独立预接触边界图完成 10 个新进程准备态。完整候选资格的失败/通过边界为 `0.0392418976--0.0399542056`，原始自净空的非正/正边界为 `0.0365174127--0.0392418976`。两者之间存在原始守卫为正但候选数值裕量不足的区域。
9. 最低采样合格上界通过残差、完整 v2 和三步长 Hessian/能量曲率交叉检查后，执行了唯一一条 `0.12 s` 无接触动力学。正式原始守卫未触发零事件，但完整候选 v2 在展示网格上于 `0.0248359375--0.02484375 s` 首次失效；没有接触后延拓，也没有取得连续守卫证书。

本轮时窗只有 `0.12 s`，用于正式后端的初始数值资格，不覆盖上一轮约 `9--15 s` 的模态分析窗。因此，外部位置指标在短窗内呈现良好收缩，也不能证明长期频率、相位、闭合或装置轨迹收敛。

三个锚点继续使用上一轮三锚点模型阶梯的几何、材料、释放状态和共享输入映射。每个锚点的柔索--高保真共享输入审计仍为 53 项全部通过。

生产配置固定为：

正式验证代码从生产层生成以下三层空间序列：

|---|---:|---:|---:|---|

候选脚本直接调用正式代码中的空间配置、材料坐标比较、Cauchy 门和事件稳定性逻辑。它没有重写另一个“近似验证器”，也没有在看到结果后放宽阈值。

源码身份需要单独说明：输入冻结阶段、修复后重跑的准备态诊断和代表性证书尝试都记录了正式源码哈希 `1c0b8a6f...`。但是，9 个历史空间运行的候选包装器错误地对不存在的 `src/src/ypendulum` 求哈希，得到空树哈希 `e3b0c442...`。配置、规格、候选脚本和运行环境的起止检查仍有效，27 个大工件也仍与原候选清单一致；只有“历史空间运行端点正式源码稳定”这一项被降为未直接验证。保留原始空间 JSON 不改写，`results/run_summary.json` 以 `identity_checks_as_recorded`、`effective_identity_checks` 和 `source_provenance_assessment` 同时呈现原记录与纠正后的判定。

## 3. 准备态诊断

下表只比较 `t=0` 的独立参考核重算结果，不是动态收敛证据。

| 锚点 | 粗层最小有符号轴力 / N | 中层 / N | 细层 / N | 细层最小归一化守卫裕量 | 初态判定 |
|---|---:|---:|---:|---:|---|
| `4:3` | -0.004411 | -0.004694 | -0.004772 | 1.091e-4 | 下支存在压缩；守卫门失败 |
| `3:2` | +0.003468 | +0.003158 | +0.003080 | 8.384e-5 | 全支严格受拉；守卫门失败 |
| `2:1` | +0.007325 | +0.007001 | +0.006920 | 3.601e-5 | 全支严格受拉；守卫门失败 |

`4:3` 的负轴力位于下支。非正轴力单元数随网格从 2 个增加到 3 个和 5 个，但物质区间保持在下支靠近摆球的一端；最小值也随细化趋近约 `-4.8 mN`。这排除了“只在 1--2 单元预览网格出现”的解释。

这里还要区分两个不同门槛：正式准备器所说的 `guards_valid=true` 只表示原始机器/几何守卫没有穿越零；本轮资格规格额外要求每个守卫具有大于 `3e-4` 的归一化正裕量。三锚点均满足前者、失败于后者，二者不能混写成同一个 PASS。

### 3.1 守卫根因分解

`results/guard_root_cause.json` 使用正式独立参考核，把公开标量守卫重新分解到支路、段、材料坐标和原始量纲。九个锚点--层级组合的 `ROD_SELF_CLEARANCE` 赢家均为下支同支候选；生产层都是最后两个离散段，受约束的两材料点间距恰好等于正式局部排除距离 `1.01 × (直径 + 最小间隙) = 3.232 mm`。生产层最小跨支原始裕量约为公开赢家的 48--52 倍。

| 锚点 | 生产层同支原始裕量 / μm | 资格所需原始裕量 / μm | 最小跨支原始裕量 / mm | 固定状态下达到阈值所需排除因子 |
|---|---:|---:|---:|---:|
| `4:3` | 30.715 | 84.488 | 1.4629 | 1.02681 |
| `3:2` | 32.830 | 117.469 | 1.5237 | 1.03644 |
| `2:1` | 33.864 | 282.109 | 1.7577 | 1.08753 |

正式同支排除因子 `1.01` 对一根近似直杆只留下约 `0.01 × (3.0 mm + 0.2 mm) = 32 μm` 的原始裕量；资格门要求的却是 `3e-4 × 全局特征长度`，所以锚点越长，要求的原始裕量越大。表中最后一列只是对当前固定状态的反事实诊断，不是建议值：修改排除域、归一化尺度或分组件门槛都会改变正式模型或资格规格，本轮没有选择其中任何一种。

`2:1` 还揭示了独立问题：生产层 `BOB_SOCKET_RADIAL_MONOTONICITY` 原始点积为 `7.705e-5 m²`，保持正值且局部径向增量余弦为 `0.874`，但全局门要求 `2.653e-4 m²`。该守卫是逐材料单元的 `径向向量 · 空间增量`；光滑外伸几何上的原始值也随单元跨度缩小，因此固定的全局归一化正裕量不是网格不变门。即使单独处理 `ROD_SELF_CLEARANCE`，`2:1` 仍会被此门关闭。

## 5. 轴力来源诊断

### 5.1 `4:3`

三层动态最小有符号轴力分别为 `-0.03572 N`、`-0.03669 N` 和 `-0.03698 N`。生产层在初态已有下支压缩，随后上下支还发生多次张力--压缩切换。当前证据把来源定位到双侧轴向材料律下的稳定准备态及其动态传播；要判断这种双侧响应是否对应真实绳索，必须另做压缩正则化和仅受拉极限研究。

### 5.2 `3:2`

三层动态最小有符号轴力与准备态相同，分别为 `+0.003468 N`、`+0.003158 N` 和 `+0.003080 N`，没有轴力事件。上一轮 2 单元细网格的 `-0.00158 N` 样本发生在本轮时窗内，却没有在 6、12、24 单元层级复现。因为本轮还同时切换到生产积分配置，最严谨的结论是“低层级数值设置相关”，而不是“已唯一证明为网格误差”。

### 5.3 `2:1`

三层动态最小有符号轴力为 `+0.007325 N`、`+0.007001 N` 和 `+0.006920 N`，没有轴力事件。它仍因守卫裕量和角速度空间指标失败，不能用“始终受拉”替代整体资格。

### 5.4 `4:3` 压缩极限预检

正式独立性规格冻结了 `alpha = 1, 1e-2, 1e-4, 1e-6`。候选预检只改变 `high_fidelity.compression_regularization_scale` 及必要的管理字段；`alpha=1` 通过正式配置检查，三个 `alpha<1` 候选全部在写盘前由正式程序以 `HF_HELD_PREPARATION_REQUIRES_BILATERAL_ROD` 拒绝。精确 `alpha=0` 仍只是正式配置契约中的数学端点，不是可执行候选。该预检阶段没有写入半合法的 `alpha<1` YAML，也没有生成动态结果；后述隔离覆盖层和边界协议属于随后单独冻结的候选研究身份。

端点几何审计说明现有替代协议不能静默替换：两条上支端点弦长分别比材料静长长 `8.521 mm`，但下支端点弦长为 `0.280046 m`，比材料静长 `0.281626 m` 短 `1.580 mm`。正式 `geometric_direct_release` 无法从这对端点推断完整的压缩直杆状态，按设计拒绝该输入。

在不绕过配置契约的前提下，本轮只对已经合法制备的 `alpha=1` 生产层状态做瞬时本构重算。正式生产核与独立参考核在五个尺度上全部交叉一致；下支五个压缩段的最小轴力依次为 `-4.772 mN`、`-47.72 μN`、`-0.4772 μN`、`-4.772 nN`，数学端点为零。几何守卫不随这次定态本构重算改变。该结果只验证代数混合按 `alpha` 连续缩放，既不是每个 `alpha` 自身的平衡准备态，也不是释放后的轨迹。

动态研究现有三种不同身份：各 `alpha` 在相同端点下分别重求平衡；把同一个 `alpha=1` 状态注入不同材料律并在释放时突变；或者改用不再保持同一摆球--接点端点对的现有制备模式。三者回答不同物理问题，不能由脚本替用户暗选。

### 5.5 完整守卫 v2 与 `alpha` 特定准备态

后续裁决保持全部正式原始守卫、接触域和严格 `3e-4` 数值门不变，只把资格裕量改为定义相应失败模式的局部无量纲量。11 个公开分量均在新结果出现前完成分类和测试：段长按对应材料静长，气动弦长按相邻两段静长之和，净空按本地所需中心距，套筒材料余量按套筒静长，摆球套筒径向点积按局部方向余弦；两个原生无量纲分量保持尺度 1。

对三个锚点的九个 `alpha=1` 网格状态重新制备和复核后，完整候选 v2 为 `9/9` 通过，最小裕量为 `6.9949e-3`。这只完成准备态的候选守卫尺度审计，不会追溯改判历史动态或空间结果。

`4:3` 主制备身份冻结为固定全部端点、每个 `alpha` 独立多种子最低能量平衡。隔离覆盖层和三个 `OUT_OF_SCOPE` 配置均完成源码身份、唯一替换、导入和配置验证。实际结果为：

- `alpha=1e-2` 有三个种子达到 `1e-8 N` 残差门，最小 Hessian 特征值约为 `+8.577e-3 N/m`，但杆自净空约为 `-0.07665 mm`；
- `alpha=1e-4` 与 `1e-6` 的最好残差分别约为 `2.424e-5 N` 和 `2.428e-5 N`，杆自净空约为 `-0.83` 至 `-1.40 mm`；
- 三个尺度所有种子的唯一非正原始分量均为 `ROD_SELF_CLEARANCE`。

原三尺度计划在准备态门失败后没有运行任何释放动力学。完整机器可读结果和观测性根因复现分别位于 `compression_limit/alpha_specific_preparation_results.json` 与 `compression_limit/failed_preparation_guard_diagnostic.json`。

后续工作没有直接跳到接触模型，而是先冻结 `precontact_boundary_spec.json`：从 `[1e-2, 1]` 两端开始执行 8 次几何中点二分，每个 `alpha` 都在新进程中独立使用同一种子族，不跨尺度热启动，且禁止动力学。10 个尺度均找到 3 个力平衡、半正定候选，主判据保持由失败到通过的单调次序。最终边界为：

| 边界 | 下界 | 上界 |
|---|---:|---:|
| 候选准备态失败 / 通过 | `0.03924189758484536` | `0.039954205589498866` |
| 原始杆自净空非正 / 正 | `0.03651741272548377` | `0.03924189758484536` |

最低采样合格上界 `alpha=0.039954205589498866` 的精确准备态残差为 `9.4954e-10 N`，三步长 240 维梯度 Hessian 最小特征值约为 `0.00756243 N/m`，独立能量方向曲率也全部为正；初态局部自净空裕量为 `3.41483e-4`。该精确状态获准执行一条冻结的 `0.12 s` 无接触动力学。

动力学完整返回 15,361 个展示样本和 16,274 个接受态，没有正式原始守卫零事件。展示样本中的最小原始杆自净空仍为正，为 `+0.665720 μm`。但是候选 v2 在 `0.0248359375 s` 的 `ROD_SELF_CLEARANCE = 3.01144e-4` 仍通过，到相邻的 `0.02484375 s` 已降为 `2.97410e-4`；赢家是 `upper_A:same_partial:6:7`，原始余量仍为 `+0.951712 μm`。该区间只是展示网格上的首次失败括号，不是连续穿越时刻。正式返回状态仍为 `UNDETERMINED / SUCCESS_SINGLE_RUN_GUARDS_UNCERTIFIED`，所以这条轨迹不能提升为动态数值资格。

边界图说明任务目标 `alpha=1e-2` 已位于当前无接触准备态域之外。继续取更大的 `alpha` 做动态扫描不会解决这一目标；若要向更小尺度推进，必须先裁决新的接触/非穿透物理，而不是继续调整优化器或资格归一化。

## 6. `3:2` 代表性单束证书尝试

生产层原始积分已完成：

- 接受步数：15,366；
- 积分运行时间：约 `372.68 s`；
- 最小有符号轴力：`+0.003080 N`；
- 最大绝对归一化能量平衡残差：`1.94e-10`；
- 最大四元数范数误差：`5.11e-15`。

抽样输出已经证明资格不能通过：`ROD_SELF_CLEARANCE` 的最小归一化裕量为 `8.384e-5`，低于 `3e-4`；15,361 个输出样本中有 12,261 个不超过门槛，持续到约 `0.09578 s`。

完整连续接受步证书最终**没有取得**。正式实现会对每个接受步重算独立 RHS、动力学缺陷、展示网格绑定和 11 个守卫组件，即使抽样前置门已经失败也不会提前返回。本次进程持续到约 10,000 秒墙钟后以退出码 143（SIGTERM）结束；没有 OOM 或正式异常输出，结束时点与执行会话外部时限一致，因此记录为 `EXTERNAL_EXECUTION_SESSION_LIMIT_INFERRED`，而不是正式证书返回的 FAIL。

原子目标目录和 `hf_single_bundle_certificate.json` 均未出现。完整积分检查点、暂存 HDF5、配置、规格和诊断均已保留并重新哈希，共 8 个文件、约 277 MB。`results/certificate_attempt.json` 固化了命令、时间、退出状态、身份和工件哈希。当前证据可以确认“抽样资格必败”和“完整证书未返回”，不能声称连续证书通过，也不能伪造一个返回的连续证书失败状态。

## 9. 下一步与停止条件

1. 完整 11 分量局部尺度候选合同已完成；若要提升为正式合同，仍需用户明确授权修改正式程序和验证规格，并从头重跑动态资格。
2. 当前无接触主路线在准备态资格边界和最低合格上界的单次动态处都已得到明确证据。继续扫描更大的 `alpha` 不能把任务目标 `1e-2`、`1e-4`、`1e-6` 带回无接触适用域，故不再自动扩展。
3. 若继续向更小 `alpha` 推进，模型负责人必须选择：终止于当前无接触边界；建立含静态 KKT 反力和动态互补/冲量的硬接触模型；或建立带新参数和校准要求的柔顺/摩擦接触模型。只在静态阶段加不穿透约束、动态阶段仍忽略接触反力是不自洽的。
4. 共享 `alpha=1` 状态后的材料律突变仍可作为第二条敏感度实验，但必须保持独立身份，不得冒充各材料律自己的平衡准备态。
5. 任何新模型都须重新冻结方程、算法、门槛和测试；随后仍须补空间、时间、双积分器和连续守卫证书。数值资格满足后，才进入可测输入、校准集、盲验证集和装置级不确定度。

在这些门禁完成前，三个锚点都不得被写成真实装置最优频率比、尺寸或稳定图样预测。
