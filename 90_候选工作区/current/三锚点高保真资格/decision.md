# 高保真守卫与 `4:3` 压缩极限裁决

## 1. 守卫资格合同

本轮不扩大同支材料排除域，也不降低预冻结的 `3e-4` 数值门槛。前两种做法都会在看到失败结果后改变测试难度，而且不能解决量纲尺度不相容。

本轮裁决采用统一原则：每项资格裕量应以定义该守卫的局部几何尺度无量纲化，而不是使用与该失效模式无关的整机特征长度。现有根因报告只提供了两项失败分量的完整局部极小值分解，因此候选实现先重算以下两项：

- `ROD_SELF_CLEARANCE`：同支和跨支原始净空分别除以其局部所需中心距；
- `BOB_SOCKET_RADIAL_MONOTONICITY`：保留每个材料单元 `r·Δr>0` 的原始符号门，并以局部方向余弦 `(r·Δr)/(|r||Δr|)` 作为无量纲裕量。

其余分量暂时沿用正式 v1 元数据，仅用于可复现的两分量混合诊断；这不代表其尺度已经被证明网格客观。尤其 `MINIMUM_SEGMENT_LENGTH`、`AERODYNAMIC_CHORD_LENGTH` 也是逐单元量，正式提升前必须按同一预声明原则完成全分量审计，不能只修正已经失败的项目。所有当前分量仍严格大于 `3e-4` 才通过。历史 v1 运行不追溯改判；新的动态资格必须在接受步或独立验证的连续证书上重新计算完整候选合同。

基于已有机器可读根因报告，九个准备态在“两项局部重归一化 + 其余 v1”混合诊断下均通过，但这只消除了已定位的准备态尺度伪失败，不能作为完整 v2 合同已经通过的证据。既有空间 Cauchy 超限、`4:3` 事件不稳定、历史源码端点探针无效和连续证书不完整均保持不变，因此整体仍为 `HF_NUMERICAL_QUALIFICATION_NO_GO`。

## 2. `4:3` 的 `alpha<1` 制备身份

主研究采用 `ALPHA_SPECIFIC_HELD_EQUILIBRIUM`：保持摆球、接点和两支点端点不变，在每个目标 `alpha` 下独立进行确定性的多种子保守能量最小化。它直接回答“同一释放几何、不同压缩正则化材料律分别制备后会怎样”。

`SHARED_ALPHA1_STATE_CONSTITUTIVE_QUENCH` 只作为第二条敏感性对照，因为它包含瞬时材料律突变，并非各材料律自己的平衡初态。改变端点的现有制备模式不作为主方案，因为它把本构极限和释放几何变化混在一起。

正式求解器已具备重力续接、力残差抛光、负曲率逃逸、Hessian 半正定审计和最低能量稳定候选选择。候选覆盖层只移除配置验证器和制备函数中的两个 `alpha=1` 专用阻断，并在审计中记录目标 `alpha`；正式目录不修改。目标尺度冻结为 `1, 1e-2, 1e-4, 1e-6`，`alpha=0` 仅保留为数学端点。

本轮尚未运行 `alpha<1` 平衡或动态。下一道门是分别证明三个候选尺度存在残差合格、经尺度敏感性复核的 PSD 稳定、原始守卫为正且完整局部尺度资格通过的定端平衡；任何尺度失败都应按 `NO-GO` 返回，而不是改用另一制备身份掩盖失败。
