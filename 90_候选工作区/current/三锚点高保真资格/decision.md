# 高保真守卫与 `4:3` 压缩极限裁决

## 1. 本轮结论

本轮完成了两道原交接门禁，结论如下：

1. 11 项正式公开守卫已经按同一局部尺度原则完成候选 v2 分类、实现、先验测试和三锚点九网格准备态复核。九个既有 `alpha=1` 准备态全部通过完整候选 v2；最小观测裕量为 `4:3` 粗层的 `ROD_SELF_CLEARANCE = 6.9949e-3`，高于保持不变的严格门槛 `3e-4`。
2. `4:3` 的三个 `alpha<1` 候选均没有产生合格的定端准备态。三个尺度所有种子的唯一非正原始守卫都是 `ROD_SELF_CLEARANCE`；`alpha=1e-4` 与 `1e-6` 还没有达到 `1e-8 N` 的力残差门。
3. 因准备态门失败，`0.12 s` 动力学门保持关闭，实际动态运行数为 0。不得从本轮结果声称压缩极限趋势、严格单边绳索极限或装置轨迹。
4. 正式理论、正式模拟程序、顶层 `AGENTS.md` 和正式验证规格均未修改。所有新增实现和结果都位于候选工作区。

整体高保真数值资格仍为 `HF_NUMERICAL_QUALIFICATION_NO_GO`。完整候选守卫 v2 解决的是既有 `alpha=1` 准备态的资格尺度定义，不会推翻历史空间 Cauchy 超限、`4:3` 事件不稳定、连续证书不完整或历史源码端点探针无效。

## 2. 完整候选守卫 v2

### 2.1 不变项

- 不扩大或缩小任何接触域、套筒域、材料排除域或离散守卫域。
- 不改变任何正式原始守卫值及其零穿越语义。
- 每项原始守卫仍须严格大于零；局部归一化不能掩盖原始负值。
- 资格门槛仍为严格大于 `3e-4`。
- 历史 v1 结果不追溯改判；动态资格仍须在接受步或独立连续证书上重新计算。

### 2.3 九网格复核结果

对 `4:3`、`3:2`、`2:1` 的 `6/6/8`、`12/12/16`、`24/24/32` 九个 `alpha=1` 状态重新执行了正式定端准备，再用冻结完整 v2 逐项复算。结果为 `9/9` 通过，合同身份在运行前后保持稳定。

九个状态的最小分量均为保留原域的 `ROD_SELF_CLEARANCE`，归一化裕量范围为 `6.9949e-3` 至 `1.05825e-2`。这证明完整分类没有通过遗漏其余分量来维持结果；它仍然只是准备态候选合同审计，不是历史轨迹重认证。

## 3. `alpha` 特定定端制备

### 3.1 制备身份和覆盖层

主研究身份保持为 `ALPHA_SPECIFIC_HELD_EQUILIBRIUM`：固定两支点、接点、摆球质心、姿态和附件端点，对每个目标 `alpha` 独立执行确定性多种子保守能量最小化，不跨尺度热启动。

隔离覆盖层先验证了两个正式 Git blob：

- `ypendulum/config/validation.py`：`7b66ae8c54a507c974d69be9ded05267dbb21439`；
- `ypendulum/hf/solver.py`：`325ad43aa8088a55defeae9851c9ccfa508fe936`。

五个源码替换点均只匹配一次，覆盖层可导入；`alpha=1e-2`、`1e-4`、`1e-6` 三份 `OUT_OF_SCOPE` 配置均通过覆盖层配置验证。正式目录在运行前后逐 Python 文件保持不变。

### 3.2 预冻结接受门

每个尺度必须同时满足：

1. 配置、声明等级、覆盖层身份和审计协议正确；
2. 自由材料力残差不大于 `1e-8 N`；
3. 从合格多种子中选择最低能量稳定候选；
4. 正式 11 项原始守卫全部严格为正；
5. 冻结完整候选守卫 v2 通过；
6. 三种有限差分步长的 240 维梯度 Hessian 谱和独立能量方向曲率检查通过。

任何一项失败都关闭动力学门，不自动切换成共享 `alpha=1` 状态的材料律突变，也不通过放宽接触域、残差或迭代门掩盖失败。

### 3.3 实际准备态结果

| `alpha` | 达到力残差门的种子 | 最好残差 / N | 已取得的稳定性证据 | `ROD_SELF_CLEARANCE` 原始范围 | 准备态判定 |
|---:|---:|---:|---|---:|---|
| `1e-2` | 3 / 4 | `1.2646e-9` | 三个力平衡分支的最小 Hessian 特征值约为 `+8.577e-3 N/m` | `-0.15895` 至 `-0.07665 mm` | 原始杆自净空失败 |
| `1e-4` | 0 / 4 | `2.4240e-5` | 残差未合格，未进入 Hessian 审计 | `-1.39917` 至 `-0.83431 mm` | 残差与原始杆自净空同时失败 |
| `1e-6` | 0 / 4 | `2.4282e-5` | 残差未合格，未进入 Hessian 审计 | `-1.38328` 至 `-0.87791 mm` | 残差与原始杆自净空同时失败 |

观测性复现只在生成覆盖层的失败记录中增加已经计算过的 11 项原始守卫字典，不改变目标函数、优化器、残差、Hessian、守卫判定、候选选择或异常行为。四个种子的能量、残差、Hessian 摘要和首轮逐项一致；三个尺度所有种子的唯一非正原始分量都是 `ROD_SELF_CLEARANCE`。

因此：

- `alpha=1e-2` 不是“优化器还没收敛”，而是已找到力平衡、正 Hessian 的保守形态后进入正式非局部杆自接触域；
- 单纯增加 `alpha=1e-2` 的迭代数不能修复该原始几何失败；
- `alpha=1e-4` 与 `1e-6` 同时存在优化残差和原始自接触问题；
- 完整候选 v2 不会也不能把负原始净空改判为通过。

## 4. 动力学裁决

三个准备态通过数为 `0/3`，故 `dynamic_gate_open=false`，动态运行数保持为 0。没有生成释放轨迹、事件序列、压缩物质区间演化、能量账或外部轨迹比较。

`SHARED_ALPHA1_STATE_CONSTITUTIVE_QUENCH` 仍只是另一种敏感度问题。它可以研究“合法 `alpha=1` 几何在释放瞬间突变材料律”的响应，但不能替代本轮已经失败的“各材料律自己的定端平衡初态”，也不能被写成主制备压缩极限。

## 5. 当前结论上限与后续选择

本轮可确认：

- 完整 11 分量局部尺度候选合同已经实现，并在九个既有 `alpha=1` 准备态上通过；
- 当前无接触约束的多种子保守能量最小化不能为三个 `alpha<1` 尺度提供正式原始守卫合格的同端点准备态；
- `alpha=1e-2` 的决定性障碍是原始杆自接触，不是 v1/v2 归一化选择。

本轮不能确认：

- 任意 `alpha<1` 的合格释放轨迹或压缩极限趋势；
- `alpha→0+` 等同于严格单边绳索互补问题；
- 正式高保真数值资格、装置物理有效性或实验预测。

若要继续主制备路线，下一项实质性模型选择应是：是否为静态制备增加预声明的非穿透接触约束或接触势，并重新冻结模型、算法和资格。那不是“多跑几次”或“调整归一化”，而是新的制备方程和数值问题。修改 `02_模拟程序/**` 仍需用户明确授权；在此之前只能在候选工作区研究。
