# 高保真守卫与 `4:3` 压缩极限裁决

## 1. 本轮结论

本轮完成原交接门禁，并继续把不引入接触物理的主路线推进到其可证边界。结论如下：

1. 11 项正式公开守卫已经按同一局部尺度原则完成候选 v2 分类、实现、先验测试和三锚点九网格准备态复核。九个既有 `alpha=1` 准备态全部通过完整候选 v2；最小观测裕量为 `4:3` 粗层的 `ROD_SELF_CLEARANCE = 6.9949e-3`，高于保持不变的严格门槛 `3e-4`。
2. `4:3` 的原定三个 `alpha<1` 目标均没有产生合格的定端准备态。三个尺度所有种子的唯一非正原始守卫都是 `ROD_SELF_CLEARANCE`；`alpha=1e-4` 与 `1e-6` 还没有达到 `1e-8 N` 的力残差门。
3. 在任何中间 `alpha` 结果出现前冻结并完成 10 点对数二分边界图。候选准备态资格的最后失败/最先通过区间为 `[0.03924189758484536, 0.039954205589498866]`；原始杆自净空的非正/正区间为 `[0.03651741272548377, 0.03924189758484536]`。这两个边界不同，不能把原始不穿透直接写成候选数值资格。
4. 最低采样合格上界 `alpha=0.039954205589498866` 通过力残差、完整 v2、三步长 240 维 Hessian 和独立能量曲率交叉检查，随后获准执行唯一一次 `0.12 s` 无接触动力学。正式原始守卫没有触发零事件，但完整候选 v2 在展示网格上于 `0.0248359375--0.02484375 s` 首次失效；因此它只给出离散候选合格前缀，不是完整动态资格。
5. 正式理论、正式模拟程序、顶层 `AGENTS.md` 和正式验证规格均未修改。所有新增实现和结果都位于候选工作区。

整体高保真数值资格仍为 `HF_NUMERICAL_QUALIFICATION_NO_GO`。完整候选守卫 v2、静态边界图和一条单次动力学都不会推翻历史空间 Cauchy 超限、`4:3` 事件不稳定、连续证书不完整或历史源码端点探针无效。

## 2. 完整候选守卫 v2

### 2.1 不变项

- 不扩大或缩小任何接触域、套筒域、材料排除域或离散守卫域。
- 不改变任何正式原始守卫值及其零穿越语义。
- 每项原始守卫仍须严格大于零；局部归一化不能掩盖原始负值。
- 资格门槛仍为严格大于 `3e-4`。
- 历史 v1 结果不追溯改判；动态资格仍须在接受步或独立连续证书上重新计算。

### 2.3 九网格复核结果

对 `4:3`、`3:2`、`2:1` 的 `6/6/8`、`12/12/16`、`24/24/32` 九个 `alpha=1` 状态重新执行了正式定端准备，再用冻结完整 v2 逐项复算。结果为 `9/9` 通过，合同身份在运行前后保持稳定。

九个状态的最小分量均为保留原域的 `ROD_SELF_CLEARANCE`，归一化裕量范围为 `6.9949e-3` 至 `1.05825e-2`。这证明完整分类没有通过遗漏其余分量来维持结果；它仍然只是准备态候选合同审计，不是历史轨迹重认证。

## 3. `alpha` 特定定端制备

### 3.1 制备身份和覆盖层

主研究身份保持为 `ALPHA_SPECIFIC_HELD_EQUILIBRIUM`：固定两支点、接点、摆球质心、姿态和附件端点，对每个目标 `alpha` 独立执行确定性多种子保守能量最小化，不跨尺度热启动。

隔离覆盖层先验证了两个正式 Git blob：

- `ypendulum/config/validation.py`：`7b66ae8c54a507c974d69be9ded05267dbb21439`；
- `ypendulum/hf/solver.py`：`325ad43aa8088a55defeae9851c9ccfa508fe936`。

五个源码替换点均只匹配一次，覆盖层可导入；`alpha=1e-2`、`1e-4`、`1e-6` 三份 `OUT_OF_SCOPE` 配置均通过覆盖层配置验证。正式目录在运行前后逐 Python 文件保持不变。

### 3.2 预冻结接受门

每个尺度必须同时满足：

1. 配置、声明等级、覆盖层身份和审计协议正确；
2. 自由材料力残差不大于 `1e-8 N`；
3. 从合格多种子中选择最低能量稳定候选；
4. 正式 11 项原始守卫全部严格为正；
5. 冻结完整候选守卫 v2 通过；
6. 三种有限差分步长的 240 维梯度 Hessian 谱和独立能量方向曲率检查通过。

任何一项失败都关闭动力学门，不自动切换成共享 `alpha=1` 状态的材料律突变，也不通过放宽接触域、残差或迭代门掩盖失败。

### 3.3 实际准备态结果

| `alpha` | 达到力残差门的种子 | 最好残差 / N | 已取得的稳定性证据 | `ROD_SELF_CLEARANCE` 原始范围 | 准备态判定 |
|---:|---:|---:|---|---:|---|
| `1e-2` | 3 / 4 | `1.2646e-9` | 三个力平衡分支的最小 Hessian 特征值约为 `+8.577e-3 N/m` | `-0.15895` 至 `-0.07665 mm` | 原始杆自净空失败 |
| `1e-4` | 0 / 4 | `2.4240e-5` | 残差未合格，未进入 Hessian 审计 | `-1.39917` 至 `-0.83431 mm` | 残差与原始杆自净空同时失败 |
| `1e-6` | 0 / 4 | `2.4282e-5` | 残差未合格，未进入 Hessian 审计 | `-1.38328` 至 `-0.87791 mm` | 残差与原始杆自净空同时失败 |

观测性复现只在生成覆盖层的失败记录中增加已经计算过的 11 项原始守卫字典，不改变目标函数、优化器、残差、Hessian、守卫判定、候选选择或异常行为。四个种子的能量、残差、Hessian 摘要和首轮逐项一致；三个尺度所有种子的唯一非正原始分量都是 `ROD_SELF_CLEARANCE`。

因此：

- `alpha=1e-2` 不是“优化器还没收敛”，而是已找到力平衡、正 Hessian 的保守形态后进入正式非局部杆自接触域；
- 单纯增加 `alpha=1e-2` 的迭代数不能修复该原始几何失败；
- `alpha=1e-4` 与 `1e-6` 同时存在优化残差和原始自接触问题；
- 完整候选 v2 不会也不能把负原始净空改判为通过。

### 3.4 预接触准备态边界

在看到任何中间尺度结果之前，`precontact_boundary_spec.json` 固定了以下协议：从 `[1e-2, 1]` 两端开始，执行 8 次几何中点二分；每个 `alpha` 都在新进程中使用相同确定性种子族独立制备，不跨尺度热启动；主判据要求先达到力残差与半正定 Hessian，再通过完整冻结守卫 v2。总计只允许 10 个唯一尺度，禁止动力学。

10 个尺度均产生 3 个力平衡、半正定候选；最低能量选择在全部尺度上保持唯一。主判据随 `alpha` 单调地由失败转为通过，得到：

| 边界含义 | 下界 | 上界 | 上下界比 |
|---|---:|---:|---:|
| 完整候选准备态资格：失败 / 通过 | `0.03924189758484536` | `0.039954205589498866` | `1.0181517` |
| 原始杆自净空：非正 / 正 | `0.03651741272548377` | `0.03924189758484536` | `1.0746078` |

在 `alpha=0.03924189758484536`，原始杆自净空已经为正，约 `+0.556 μm`，但局部归一化裕量只有 `1.7375e-4`，仍低于严格 `3e-4` 门槛。因此原始几何不穿透只表示仍在正式物理域内，不能替代候选数值资格。

最低采样合格上界随后由独立工人重新制备和交叉检查。精确状态归档 SHA-256 为 `0c2ac347...`，力残差为 `9.4954e-10 N`；三种梯度 Hessian 步长的最小特征值为 `0.0075624254`、`0.0075624277`、`0.0075624369 N/m`，三种独立能量方向曲率均为正。初态 `ROD_SELF_CLEARANCE` 原始余量约 `1.09274 μm`，局部归一化裕量 `3.41483e-4`，刚刚高于门槛。

## 4. 动力学裁决

原定 `alpha=1e-2`、`1e-4`、`1e-6` 三目标计划仍为准备态通过数 `0/3`、动力学数 0。后续边界研究是身份独立的新冻结协议：只有最低采样合格上界的精确状态通过全部准备门后，才执行一条无接触、遇正式原始守卫零事件即停止、禁止接触后延拓的 `0.12 s` 动力学。

该唯一动力学的结果为：

| 项目 | 结果 |
|---|---|
| `alpha` | `0.039954205589498866` |
| 展示样本 / 接受态 | `15361 / 16274` |
| 正式原始守卫零事件 | 未出现 |
| 正式展示样本最小杆自净空 | `+0.665720 μm`，位于 `0.0251875 s` |
| 候选 v2 最后通过 | `0.0248359375 s`，`3.01144e-4` |

候选首次失效只在相邻展示样本之间定位，区间宽 `7.8125 μs`；没有取得连续穿越时刻或接受步连续守卫证书。正式求解器完整返回 `[0, 0.12] s`，只表示未发现括号化原始零事件，不能把原始正余量或单次能量账写成连续数值资格 PASS。运行没有使用接触力、碰撞、摩擦或接触后延拓。

`SHARED_ALPHA1_STATE_CONSTITUTIVE_QUENCH` 仍只是另一种敏感度问题。它可以研究“合法 `alpha=1` 几何在释放瞬间突变材料律”的响应，但不能替代本轮已经失败的“各材料律自己的定端平衡初态”，也不能被写成主制备压缩极限。

## 5. 当前结论上限与后续选择

本轮可确认：

- 完整 11 分量局部尺度候选合同已经实现，并在九个既有 `alpha=1` 准备态上通过；
- 当前无接触约束的多种子保守能量最小化不能为三个 `alpha<1` 尺度提供正式原始守卫合格的同端点准备态；
- `alpha=1e-2` 的决定性障碍是原始杆自接触，不是 v1/v2 归一化选择；
- 接触自由准备态资格边界位于约 `0.03924--0.03995`，而最低合格上界的单次释放也在约 `24.84 ms` 失去候选 v2 数值裕量。

本轮不能确认：

- 任意 `alpha<1` 的合格释放轨迹或压缩极限趋势；
- `alpha→0+` 等同于严格单边绳索互补问题；
- 正式高保真数值资格、装置物理有效性或实验预测。

继续计算更大的 `alpha` 最多只能再定位“哪种较强双侧压缩模型能在短窗保持候选裕量”，不能把准备态边界推到任务目标 `1e-2`、`1e-4`、`1e-6`，因此不再自动扩展。

若要继续主制备路线，必须由模型负责人在以下物理身份之间裁决：

1. 把约 `0.03924--0.03995` 视为当前无接触模型的适用域边界，终止向更小 `alpha` 的主路线；
2. 引入无摩擦硬非穿透约束，并同时定义静态 KKT 接触反力、动态互补/冲量和接触事件算法；
3. 引入柔顺和可能带摩擦的接触势，同时新增刚度、阻尼、摩擦参数及其校准证据；
4. 另行运行共享 `alpha=1` 状态后的本构突变敏感度，但明确它不是各 `alpha` 自身平衡初态或压缩极限。

只给静态最小化器增加不穿透约束、释放后仍沿用无接触动力学是不自洽的：一旦约束激活，静态 KKT 乘子代表的接触反力在动态方程中没有对应项。任何接触选项都属于新的物理与数值问题，必须先重新冻结方程、参数、算法、门槛和测试。修改 `02_模拟程序/**` 仍需用户明确授权；在此之前只能停在本候选证据边界。
