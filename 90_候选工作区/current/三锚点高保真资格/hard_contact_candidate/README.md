# 无摩擦硬接触候选：逐接触间隙与静态 KKT 原语

## 定位

本目录只属于候选工作区，不修改正式理论或正式模拟程序。当前目标不是直接生成一条“带接触的高保真轨迹”，而是回答更前置的问题：在保留正式杆径、最小净空、同支材料排除域和结点套筒裁剪的条件下，目标压缩尺度是否存在由法向接触反力支撑的稳定定端平衡态。

原正式实现的 `ROD_SELF_CLEARANCE` 是所有已登记杆段对净空的全局最小值。它适合做失效守卫，但不适合作为接触 KKT 的唯一约束：接触反力需要知道每一项间隙 $g_i$、接触对身份、最近点参数、法向和雅可比 $J_{g_i}$。因此本候选先建立逐接触对原语。

## 已实现

`geometry_kkt.py` 作为兼容导出层；实现按 `types.py`、`parameter_domain.py`、`witness.py`、`assembly.py`、KKT 分层模块和 `static_solver.py` 拆分，提供：

1. 普通线段对的单位方形参数域；
2. 与正式同支材料排除规则等价的凸参数域裁剪；
3. 最近点见证、非唯一见证识别和端点间隙梯度；
4. 多接触约束的全局节点雅可比装配；
5. 非负法向乘子重构；
6. 有量纲静态 KKT 审计；
7. 通用 SLSQP 静态可行性驱动；
8. 活跃约束零空间上的 Hessian 半正定充分检查。

静态合同为

$$
 g_i(q)\ge 0,\qquad \lambda_i\ge 0,\qquad
 \lambda_i g_i(q)=0,
$$

$$
 \nabla\Pi(q)-J_g(q)^{\mathsf T}\lambda=0.
$$

此处 $J_g^{\mathsf T}\lambda$ 是法向接触广义力。零空间 Hessian 检查只是一项充分检查；弱活跃约束的完整二阶条件仍需临界锥分析。

## 明确未完成

尚未把正式 `HighFidelityModel` 中的同支 `full_pairs`、`partial_pairs` 和跨支结点套筒活动段逐项适配到本模块；尚未对 `alpha=1e-2`、`1e-4`、`1e-6` 运行接触平衡制备；尚未实现动态互补、冲量、摩擦或恢复系数模型。因此本目录不能推翻 `HF_NUMERICAL_QUALIFICATION_NO_GO`，也不能说明压缩极限已经数值实现。

## 后续门禁

下一步必须先冻结正式登记到逐接触约束的适配器和目标尺度运行协议，再只运行静态 KKT 制备。至少一个目标尺度通过间隙、乘子、平衡、互补和稳定性门之后，才允许设计动态硬接触积分。静态约束态不得直接释放进当前无接触 ODE。
