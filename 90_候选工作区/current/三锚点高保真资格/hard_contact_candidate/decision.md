# 自接触模型裁决与候选静态 KKT 门

## 1. 裁决

本轮选择分阶段的**无摩擦刚性单边法向接触**，但只推进静态 KKT 可行性层；动态接触层继续关闭。

没有选择直接终止压缩极限研究，因为刚性静态接触不需要新增接触刚度和阻尼，仍可检验目标 `alpha` 是否存在合法受约束平衡态。没有选择柔顺接触，因为仓库当前没有法向接触刚度、阻尼、摩擦或表面形变的实验标定；此时使用罚函数得到的轨迹会依赖不可辨识参数，不能自动提升预测可信度。

## 2. 形成裁决的源码事实

1. 正式 `_rod_self_contact_margin` 把同支完整段对、同支部分材料域和跨支结点套筒域压缩为一个最小净空标量，只返回守卫值，不返回逐接触见证、法向或接触力。
2. 正式定端制备的保守目标调用 `compute_contact=False`，先做无约束能量最小化，再把净空作为事后资格门。
3. 正式 `rhs` 同样调用 `compute_contact=False`；动力学在守卫零穿越时终止，不会在接触后继续。
4. 已有 `alpha=1e-2` 结果已经同时满足力平衡和正 Hessian，但原始杆自净空为负；这不是增加无接触优化迭代数能够修复的问题。

因此，“静态加不穿透约束、随后仍使用当前无接触 ODE”不是一致模型；它会在释放瞬间删除支撑平衡的接触反力。

## 3. 本轮候选实现

新增 `hard_contact_candidate` 候选模块组（`geometry_kkt.py` 为兼容导出层），实现：

- 固定参数域上的逐线段对最近点见证；
- 正式同支材料分离半空间的凸多边形裁剪；
- 唯一见证条件下基于包络定理的间隙雅可比；
- 全局节点约束装配；
- 非负法向乘子最小二乘重构；
- 原始可行性、对偶可行性、平衡与互补的有量纲 KKT 审计；
- 通用静态受约束能量最小化原型；
- 活跃约束零空间 Hessian 半正定充分检查。

非唯一平行接触、零距离见证和塌缩线段均失败关闭，不通过任意选取法向掩盖非光滑性。

## 4. 结论边界

本轮只完成了接触路线的模型裁决和可测试数学原语，没有完成正式登记适配器，也没有运行任何目标 `alpha` 接触制备。当前正式结论保持：

`HF_NUMERICAL_QUALIFICATION_NO_GO`

更具体地说：无接触压缩路线已经到达可证边界；刚性接触路线现在具备候选静态 KKT 基础，但尚无物理运行结果；柔顺接触路线在缺少校准时不应作为默认替代。

## 5. 下一项唯一主任务

建立正式接触登记到逐约束集合的只读适配器，并在看到结果前冻结以下内容：

1. `full_pairs`、`partial_pairs` 与结点套筒活动段的逐项身份；
2. 每项所需中心距、参数域和雅可比复算；
3. KKT、二阶稳定性和多种子选择门；
4. 首个且仅首个目标运行 `alpha=1e-2`。

若 `alpha=1e-2` 静态 KKT 失败，则先诊断几何不可行性或约束奇异性，不继续动态层；若通过，再冻结 `1e-4`、`1e-6` 的静态协议。动态互补或冲量模型必须另行裁决。
