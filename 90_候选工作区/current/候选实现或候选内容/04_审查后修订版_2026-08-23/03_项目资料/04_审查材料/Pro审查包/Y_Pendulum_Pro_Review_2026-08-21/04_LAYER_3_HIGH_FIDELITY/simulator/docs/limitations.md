# 当前 HF 限制与停止规则

1. 三支材料绳在有限质量结点固结；不支持穿环滑动、打结重排或材料交换。
2. 有中心线弯曲但没有材料 director、扭转、剪切和截面各向异性；不是完整 Cosserat/DER。
3. 摆球是各向同性球形刚体；不支持非球形惯量、质心偏置或自转气动矩。
4. 有偏心连接力矩，但结点本身仍是无转动自由度的有限质量粒子。
5. 摆球—杆和杆—杆只作终止守卫；没有接触后的冲量、摩擦、粘附、柔顺接触或穿透继续。
6. 支点可固定或规定运动；没有柔性支架与摆的双向耦合。
7. 空气力是局部线性/二次阻力闭合，不是 CFD 或流固耦合。
8. (E,\eta,C_D) 等仍需独立测量或有界依据；Newton 定律不会唯一给出这些参数。
9. 当前材料只支持注册的被动单边/双边 Kelvin–Voigt 凸组合。正式 HF 取双边杆端点 \(\alpha=1\)，受控极限才允许 \(\alpha<1\)；旧 H1 表格材料不会被静默复用。
10. 初始姿态固定为单位四元数；若要任意姿态输入，须扩展 schema、初态合同和测试。
11. 轴向拉伸/压缩状态转换按输出样本给出括号；几何有效域守卫另用积分接受步和根定位处理。原始无根结果仍保守标为 `UNDETERMINED / SUCCESS_SINGLE_RUN_GUARDS_UNCERTIFIED`，直到短窗独立连续守卫复核完成。
12. 接触守卫、段塌缩、非有限状态或无法认证的切触会失败关闭；不会继续输出超出范围轨迹。
13. 高刚度细网格很昂贵；程序设材料珠、输出样本、接受步、内存和结果大小上限。单条隐式轨迹通常主要占用一个 CPU 核，独立成员可并行；当前没有已经证明更快的 GPU 路径。
14. 统一比较只在公共状态/观测子集上进行；模型差异不是数值误差，也不是自动 pass/fail。
15. 实验接口只接受明确米制轨迹；像素需要未来冻结的相机标定合同。
16. 没有冻结真实实验数据，因此科学声明上限为 `VERIFIED`。
17. 旧 `full`/H1、旧 manifest、旧 reference outputs 和旧 ZIP 仅属历史候选，不证明当前 HF 源码。
18. 结构性理论明确不在本阶段内；不能把一次数值差异直接写成普适规律。
