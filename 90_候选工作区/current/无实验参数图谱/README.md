# Y 形摆：无实验阶段的参数—图样预测图谱

## 1. 现在应该做什么

仓库已经具备理想环面模型、连续柔索模型、高保真模拟器、有限振幅修正和张紧条件。当前无实验阶段最缺的不是另一套通用方程，而是把既有理论转化为一组可重复、可证伪的“参数 → 图样”预测：

- 扫描多个低阶有理频率比，而不是继续只看单个 `3:2` 算例；
- 区分零振幅几何、四阶有限振幅预补偿和数值调谐；
- 把相对相位视为独立图样参数；
- 给出公共周期后的相位漂移、状态闭合误差和制造容差；
- 先用理想模型筛选少量锚点，再进入连续柔索和高保真模型，避免无边界大扫描。

因此，本目录完成一套理想、对称、始终张紧的环面模型基线。它不修改 `01_最终理论/` 和 `02_模拟程序/` 中的正式成果。

## 2. 已完成的计算

扫描目标频率比：`4:3`、`3:2`、`5:3`、`2:1`。

扫描静止释放振幅：

- `(A_phi, A_theta) = (0.05, 0.04)` rad
- `(0.10, 0.08)` rad
- `(0.15, 0.10)` rad
- `(0.20, 0.12)` rad

每个组合比较三种几何：

1. 零振幅设计 `eta_0 = h/ell = (p/q)^2 - 1`；
2. 四阶正规形补偿 `eta_4`；
3. 对给定振幅、初始相位和拟合窗进行有限窗旋转率调谐的 `eta_N`。

长期指标使用 18 个慢模态周期。对于本轮 `q = 1, 2, 3` 的目标，18 是 `q` 的整数倍，因此对应整数个完整 Lissajous 公共周期；任意数量的慢周期不能都称为闭合时刻。

无量纲模型为：

```text
phi''   = -(eta + cos(phi)) sin(phi) theta'^2 - sin(phi) cos(theta)
theta'' = [2 sin(phi) phi' theta' - sin(theta)] / [eta + cos(phi)]
```

输出包括两个有限窗相位旋转率、频率比、共振相位 `Psi = q psi_phi - p psi_theta`、公共周期后的归一化四状态闭合误差、能量漂移、环面半径和三支张力守卫。

## 3. 主要结果

本轮共计算 16 个“频率比—振幅”组合，每个组合积分三种几何，共 48 条长期轨迹。

- 零振幅几何在 18 个慢周期后的最大共振相位误差约为 `1.12205 rad`。
- 四阶补偿把 16 个算例的相位误差中位数降低约 `22.20` 倍。
- 四阶补偿后的最大残余相位误差约为 `0.0628761 rad`。
- 数值调谐后的最大残余约为 `3.91697e-4 rad`。这是理想模型内有限窗调谐精度，不是实验精度。
- 四阶补偿与数值调谐的最大几何差约为 `4.967e-4`。当 `ell = 0.300 m` 时，相当于约 `0.149 mm` 的高度差。

### 代表性 `3:2` 算例

取 `A_phi = 0.15 rad`、`A_theta = 0.10 rad`、`ell = 0.300 m`：

| 方案 | `h/ell` | 相对零振幅设计的高度修正 | 18 慢周期相位误差 | 四状态闭合误差 |
|---|---:|---:|---:|---:|
| 零振幅几何 | 1.250000000 | 0 | -0.253304 rad | 1.26560e-1 |
| 四阶补偿 | 1.253515625 | +1.05469 mm | +0.0114549 rad | 5.72744e-3 |
| 数值调谐 | 1.253365103 | +1.00953 mm | +1.24018e-4 rad | 6.20080e-5 |

这表明“按小振幅频率比制造”和“在有限振幅下长期闭合”不是同一要求。毫米量级的有限振幅补偿足以决定十几个周期后图样是否明显漂移。

### 相对相位

在固定 `3:2`、固定振幅和固定调谐几何下，仅改变初始共振相位，二维轨迹的交叉点、退化切触和视觉手性就会改变。因此不能只凭一张二维轨迹的瓣数反推频率比，频率比相同也不等于图样相同；相机投影还会进一步改变外观。

### 长期闭合对几何误差的敏感性

在线性几何律附近，若要求经过 `N` 个慢周期后满足 `|Psi| <= Psi_tol`，局部估计为：

```text
|Delta eta| <= Psi_tol p / (pi q^2 N)
```

取 `N = 18`、`Psi_tol = 0.10 rad`、`ell = 0.300 m`：

| 目标比 | `h/ell` 容许误差 | 对应高度容许误差 |
|---|---:|---:|
| 4:3 | ±7.8595e-4 | ±0.236 mm |
| 3:2 | ±1.3263e-3 | ±0.398 mm |
| 5:3 | ±9.8244e-4 | ±0.295 mm |
| 2:1 | ±3.5368e-3 | ±1.061 mm |

这个容差律是目标比附近的局部线性估计，不应外推到任意振幅、失张状态或真实柔索。

## 4. 数值验证

本轮实际执行并通过：

1. 快、慢纯模态在 `0.05` 和 `0.20 rad` 下与椭圆积分精确周期比较，最大相对差约 `3.76e-16`；
2. 16 个数值调谐算例的最大相对能量漂移约 `1.65e-12`；
3. 四个目标在最大扫描振幅下进行最大步长 `0.16 → 0.08` 的减半检查：频率比差不超过 `5.2e-14`，共振相位差不超过 `1.5e-11 rad`，闭合误差差不超过 `5.8e-12`；
4. 48 条正式报告轨迹在采样窗内均保持环面半径和三支张力守卫为正；
5. 生成的 Markdown、CSV、JSON 和 SVG 在本地完成解析、渲染和摘要检查。

这些属于实现级和理想模型数值验证，不是连续柔索模型、高保真模型或实验验证。

## 5. 结论边界

本轮支持：

- 在理想对称张紧环面分支内，频率比、两个模态振幅、相对相位、几何误差和观察窗长度都对图样有可分辨影响；
- 四阶正规形是有效的有限振幅制造初值；
- 长期闭合的几何容差可进入亚毫米量级，并随 `q^2 N / p` 收紧。

本轮不支持：真实装置达到数值调谐值；已验证分布质量、柔度、结点质量、摆球尺寸、阻力或接触；已观察到锁频、迟滞、分岔或混沌；16 个点构成完整参数空间；结论在失张、压缩或接触后仍成立。

## 6. 下一步

不应立刻进行无边界的高保真扫描。应选三个锚点建立模型阶梯：

1. `4:3`、`(0.05, 0.04)`：检验接近线性极限时的模型映射；
2. `3:2`、`(0.15, 0.10)`：检验分布质量和柔度是否系统性移动有限振幅预补偿；
3. `2:1`、`(0.20, 0.12)`：检验高阶耦合和内部自由度是否开始破坏二模态描述。

每个锚点依次运行理想环面、连续柔索和高保真模型，统一比较两条相位、闭合误差、三支轴力/张力、能量账和首个守卫。完成空间、时间和模型身份检查后，才适合转化为装置尺寸建议。
