### 2.2 A：参数—图样图谱正式化迁移稿

3. 输出 schema 对 `configuration`、`validation` 和单算例结果仍允许未登记字段，多项数组只声明为一般 object，不能作为严格确定性正式合同；

5. 适配器把正式项目路径插入全局 `sys.path` 后不恢复，可能污染同进程中的后续导入；
6. 现有五项测试主要覆盖 smoke、schema 和字节确定性，缺少恶意/错误输入、来源漂移、运行时绑定和全量输出合同的失败关闭测试。

### 2.3 S：离散杆—刚体无接触静态参考迁移稿

该包的新模型身份和接触/P3R 排除方向正确，但当前分发树仍不是“最小静态包”：

1. 公共 API 仍导出 `IsotropicDragLaw`、空气力/功率/耗散、`advance_rotation_body` 等动力学或耗散接口；
2. `MassProperties` 仍提供动能和总动量，状态合同仍保存节点速度、摆球速度和角速度；
3. 生产源码和 docstring 大量保留 `HFV2State`、`HFV2Topology`、`YPS-HFV2-STATIC-ASSEMBLY-IDENTITY` 等旧候选身份，不是完整的新模型语义迁移；
4. 当前范围测试主要按文件名和导入字符串排除 `contact`、`p3r`、`dynamic`，无法发现上述语义上的动力学/耗散能力；
5. `StaticReferenceAuditThresholds` 没有失败关闭的输入验证，可接受空序列、非有限值、负阈值或不一致的严格下降步数；
6. 公共批结果没有形成规范的单次运行绑定对象，尚未完整记录组装 token、种子身份/哈希、求解器设置、审计阈值、源码清单和运行时身份。
