## 3. Pro 复审确认的根因

### 3.1 两项零乘子套筒边界是正式登记的结构结果

目标上支—下支所需中心距为：

`0.005 + 0.005 + 0.002 = 0.012 m`

结点套筒材料长度为：

`2 × 0.012 = 0.024 m`

在解析对称位置，从结点沿左上支到套筒边界的点为：

`[-0.012, 0, -0.0207846096908265] m`

竖直下支中心线上存在同深度点：

`[0, 0, -0.0207846096908265] m`

二者距离严格为 `0.012 m`。右侧产生镜像结果。正式套筒活动域保留公共边界，因此两项上支—下支约束必然是零间隙弱活动约束，而不是 `1e-7 m` 阈值或舍入制造的假活动。

G3 指标与解析复算一致：

- 间隙活动集合：4 项；
- 间隙活动 Jacobian 秩：3；
- 正乘子支撑集合：2 项摆球—上支约束；
- 正乘子支撑秩：2；
- 两个正乘子约为 `0.288532254841271 N`。

冻结清单要求间隙活动身份恰为两项摆球接触并满行秩 `2/2`，与正式登记矛盾。因此历史 NO-GO 正确；不得删除零乘子约束后追溯改判。

### 3.2 套筒有效域与唯一 SLSQP 的接口不相容

当前 `ContactStaticAssembly.evaluate` 对有限的套筒有效域违反直接抛 `DegenerateContactGeometry`，而 `solve_contact_seed` 只把接触间隙和间隙 Jacobian 交给 SLSQP。

因此：

- `seed_01_infeasible_skew` 在第一次有效求解评价前即因结点套筒投影开度失败，没有进入可行性恢复；
- `seed_02_feasible_counter_skew` 初始状态可评价，但一次有限 SLSQP 试探进入摆球套筒径向单调性失效域后立即终止。

冻结的“三个种子都返回候选”门与当前异常接口互不相容。这不能证明目标可行域为空。

P3R 必须把有限但不满足套筒有效域的状态表示为有身份、有单位、有符号残差及 Jacobian；只有非有限状态、塌缩段、零距离法向、分离的等价最近点等真正未定义几何继续失败关闭。最终候选仍必须满足全部有效域门。

### 3.3 当前 KKT 与二阶门混淆弱活动约束

当前审计把全部 `g_i <= 1e-7 m` 约束投入 NNLS、活动满秩门和二阶等式切空间。对 `g_i=0, lambda_i=0` 的弱活动约束，全部活动行满秩不是 KKT 的必要条件；把所有弱活动约束强制为 `J_i d=0` 也不是一般不等式临界锥。

P3R 必须分别定义并审计：

- 近活动或间隙活动集合；
- 正乘子支撑集合；
- 乘子非唯一性或对偶反力区间；
- 真实不等式临界锥；
- 临界锥上的二阶充分条件。

不得只删除弱活动行，也不得只放宽旧秩门。

### 3.4 前置测试没有覆盖集成语义

冻结的 21 项测试有效覆盖局部最近点、裁剪、退化、解析 Jacobian、一自由度 SLSQP/NNLS 和重复活动行失败门。但证据生成器只检查四个测试文件的退出状态和通过数量，没有把机器清单中的七个前置基准身份逐项绑定到测试节点。

`build_small_symmetric_contact_benchmark` 已存在，但没有进入前置证据调用路径。目标运行前没有执行一个同时覆盖正式 Y 形套筒、摆球双接触和活动身份预期的集成基准。
