[02-当前状态与下一步.md](每次任务前阅读/02-当前状态与下一步.md)。

根目录归档 **01_最终理论.tar.xz** 暂不迁移：纠正证据已把它的根路径、Git blob
和 SHA-256 绑定为仓库边界的一部分。它被明确归类为成熟基线伴随归档，而不是未分类文件。

## Git 约定

本仓库只使用 **main** 一个 Git 分支。工作区中的阶段成果直接在 **main** 形成范围清楚的
commit 并 push，供其他协作者从 GitHub 继续；不得为开发、审查、交接或晋升另建 Git 分支。
候选与成熟内容之间的隔离已经由目录结构、验收记录和晋升流程承担。

是否“成熟”只由验收与晋升流程决定，不由是否已经 commit、push，也不由候选目录内部是否
含有“最终”“release”或版本号等名称决定。
