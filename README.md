# IYPT 2027 第 5 题：Y 形摆

本仓库研究 IYPT 2027 第 5 题 **Y-shaped pendulum**。系统由两个上支点、三条相连支路、连接结点和摆球组成；项目关注其三维运动，以及绳长、几何、质量、弹性、阻力、支点条件和初态对轨迹与振动形态的影响。

## 项目目标

建立从装置参数和初始状态到完整运动历程的可计算模型，并在同一框架下研究模态耦合、频率比、共振、失谐、失张与重新接合、稳定性及复杂轨道。仓库同时保留降阶前向模型、高保真模拟与结构性分析，便于交叉核验。

## 仓库结构

- [`01_最终理论/`](01_最终理论/)：前向预测理论、数值计算理论和结构性理论。
- [`02_模拟程序/`](02_模拟程序/)：前向求解器、高保真模拟器、参考模型和分析程序。
- [`90_候选工作区/`](90_候选工作区/)：尚未正式提升的研究、审计、验证证据和交接记录。
