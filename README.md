# IYPT 2027 第 5 题：Y 形摆

本仓库研究 IYPT 2027 第 5 题 **Y-shaped pendulum**。装置由两个上支点、两条上支、一个汇合结点、一条下支和摆球构成。与普通单摆相比，Y 形几何同时引入了三维约束、结点运动、绳张力重分配、多个振动模态以及失张—重新受拉等问题。

项目目标不是只解释某一种轨迹，而是建立从装置参数、外部输入和完整初态到运动历程的闭合前向映射，并进一步研究频率、模态耦合、共振、失谐、轨道闭合、稳定性和复杂运动。

## 研究内容

仓库按相互区分但可交叉核验的层次组织：

1. **前向预测理论**：给定几何、材料、质量、支点运动、空气场和初态，计算三条支路、连接结点及摆球的运动。
2. **前向理论的数值实现**：把连续方程或降阶方程离散为可运行求解器，并检查收敛、事件处理、能量和张力。
3. **高保真模拟与参考模型**：用更完整的空间离散或替代模型审查降阶假设。
4. **结构性研究**：研究模态频率比、共振、失谐、闭合轨道、分岔和复杂动力学。

当前前向理论包含两套从初始时刻起独立选定的物理模型：

- **连续柔索模型**：规范主模型，用于描述有质量、可伸长、可松弛的三支柔索。
- **理想环面模型**：解析降阶模型，用于研究严格张紧、无质量且不可伸长的理想几何极限。

两套模型的状态空间不同，不能在同一条轨迹中临时互换。详细方程见 [`01_最终理论/01-前向预测理论.md`](01_最终理论/01-前向预测理论.md)。

## 前向预测理论采用的物理假设

以下假设是为了把开放题转化为确定初边值问题而作出的模型选择，并非 IYPT 题面额外规定，也不应被当作所有实际 Y 形摆都天然满足的事实。

### 一、连续柔索主模型

#### 1. 拓扑与连接

- 两条上支和一条下支是三段独立材料柔索，在连接结点 \(J\) 处汇合。
- 三支在结点处为**无滑移材料连接**：各材料端点身份固定，不允许绳穿过滑环重新分配长度。
- 若实验装置使用一根穿环滑动的连续上绳、可转动滑轮或可滑移结点，则长度约束和张力分配已经改变，不属于当前主模型。

#### 2. 柔索的连续介质理想化

- 每条支路以一维中心线和无载参考弧长材料坐标描述。
- 柔索具有分布质量、有限轴向拉伸刚度和轴向材料耗散。
- 当前本构采用平滑的、**仅受拉 Kelvin–Voigt 轴向本构**：伸长时产生弹性和黏性轴力，压缩时不承担负张力。
- 模型保留轴向伸长和松弛，但不解析弯曲刚度、扭转刚度、横向剪切、截面转动及绳内部更复杂的迟滞或内变量。
- 材料参数只在预先声明的伸长率—伸长率速度有效域内使用；达到材料失效、过度伸长或中心线切向退化边界时，预测停止。

#### 3. 连接结点与摆球

- 连接结点被视为具有有限质量 \(m_J>0\) 的点状连接件。
- 摆球在主模型中被视为点质量 \(m>0\)，只计算质心平动，不计算有限尺寸刚体的姿态、转动惯量或表面接触。
- 摆球可通过给定空气密度和排空气体积计入浮力；其余未显式建模的局部作用必须作为外力输入，而不能隐含在质量或绳长中。

#### 4. 支点与外部环境

- 两个上支点的位置 \(A(t)\)、\(B(t)\) 是预先给定的规定函数；固定支点只是 \(A,B\) 为常向量的特例。
- 支点可以不等高、可以运动，但当前模型不计算支架受绳力后的反向响应。若支架自身会振动，支架自由度必须加入新的耦合模型。
- 重力场取为空间均匀、方向固定。
- 空气速度场被视为已知外部输入。静止空气对应零速度场。
- 柔索空气阻力按局部切向与法向分量分解，并允许线性和二次阻力；摆球采用线性和二次阻力闭合。这些阻力系数需由测量、校准或明确的参考预设给出。
- 分布外力、结点外力和摆球外力可以作为规定输入加入，但不能在求解过程中临时调整以匹配结果。

#### 5. 初始条件与相容性

- 必须给定三支柔索的初始中心线和速度场，以及结点、摆球的初始位置与速度。
- 三个共享端点处的位置和速度必须相容；不相容初态不能被求解器用隐藏冲量自动修补。
- 支点运动、空气场和外力必须在整个预测区间内预先给定，前向方程不允许使用未来实验结果反推当前状态。

#### 6. 未包含的物理过程

当前连续柔索模型不在方程内部解析：

- 连接处滑移或滑轮摩擦；
- 绳断裂、塑性、磨损和材料迟滞；
- 绳—绳、绳—摆球或绳—环境接触；
- 自交后的接触力与摩擦；
- 柔索弯曲、扭转和有限截面动力学；
- 有限尺寸摆球的姿态与转动；
- 动态支架反馈。

这些事件可通过预先定义的退出守卫检测。首个守卫被触发后，当前模型只报告最后可信状态和退出原因，不应继续把数值轨迹解释为真实运动。

### 二、理想环面降阶模型

理想环面模型采用更强的解析假设：

- 两个上支点固定、等高且水平分离，三段长度满足相应三角几何条件。
- 两条上支和下支均无质量、不可伸长，长度严格固定。
- 连接结点无独立有限质量自由度，摆球为点质量。
- 三条支路始终严格正张力，摆球运动被限制在由几何约束形成的二维环面上。
- 只保留重力和理想约束，不包含柔索弹性、材料耗散、空气阻力、支点运动或接触。
- 环面半径退化或任一支路张力降至零时，模型立即到达有效域边界。

该模型适合推导几何关系、线性频率、有限振幅修正、频率比和理想闭合轨道，但不能代替连续柔索模型处理失张、绳形传播、有限刚度或重新受拉。由于四个环面状态变量不足以恢复三条完整柔索的形状，达到失张边界后也不能无歧义地切换到连续柔索模型。

## 主要输入与输出

连续柔索模型的主要物理输入包括：

- 三支无载长度、线密度、轴向刚度、轴向黏性和材料有效域；
- 连接结点质量、摆球质量、摆球排空气体积；
- 两个支点的空间位置或运动历程；
- 空气速度场、柔索和摆球阻力系数；
- 完整初始绳形、速度场、结点和摆球初态；
- 观察时段及接触、失效或其他模型外事件的退出守卫。

理论和程序应输出或能够重建：

- 三条柔索的三维中心线、速度、伸长率和轴力分布；
- 连接结点与摆球的轨迹、速度和加速度；
- 各支路受拉、松弛和重新受拉状态；
- 能量输入、材料耗散、空气阻力功率和边界功；
- 首次失张、材料越域、几何越域或其他退出事件；
- 在理想环面分支上的角坐标、频率、张力和轨道闭合指标。

## 适用范围与证据边界

前向方程的闭合性表示：合法输入给定后，在声明的物理有效域内无需临时补充规则。它不表示所有参数已经被实验识别，也不表示模型已经自动获得真实装置的定量预测资格。

需要严格区分：

- 方程的量纲、符号和能量一致性；
- 数值实现通过测试；
- 网格、时间步和事件位置收敛；
- 模型参数经过独立测量或校准；
- 对未参与校准的实验完成盲验证。

只有后几项同时满足，才能把程序结果表述为装置级预测。理想模型内部一致、单次仿真稳定或轨迹看似合理，均不能替代上述验证。
