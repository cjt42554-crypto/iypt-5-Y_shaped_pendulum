## 3. NumPy 兼容错误复核

### 3.1 事件资格工具

触发失败的表达式为：

```python
integrate = getattr(np, "trapezoid", np.trapz)
```

`getattr` 的第三参数在函数调用前求值。新 NumPy 没有 `np.trapz` 时，即便第一个属性 `np.trapezoid` 存在，也会先抛出 `AttributeError`。两项修订测试因此失败。

### 3.2 前向求解器

前向柔索和收敛后处理仍直接使用 `np.trapz`。原样运行得到 13 项失败；在测试进程内临时执行：

```python
np.trapz = np.trapezoid
```

完整测试转为通过。这一 A/B 结果说明：

1. 当前直接失败原因已被可靠隔离；
2. 大部分求解器逻辑并没有因这批失败表现出另一个独立错误；
3. 仍不能把临时 monkeypatch 当作源码已验证；
4. 必须覆盖 CLI、测试、GUI 子进程和所有独立导入路径，而非只在 desktop worker 中注入别名。

可以推出：
