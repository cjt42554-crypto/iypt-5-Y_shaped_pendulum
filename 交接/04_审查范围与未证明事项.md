## 3. 明确未完成的工作

### 3.1 没有重新证明三套理论

本次没有从公理和变分原理重新完整推导前向理论、数值理论和结构性理论，也没有对每个公式逐行复算。源码审查关注的是 Pro 针对既有审查意见做出的修改是否真实、连贯和有证据。

因此本报告不能被引用为“全部理论已完成独立数学证明”。

### 3.2 没有生产规模长时 HF 资格矩阵

本次只做了三次 2 ms、`12/12/20` 网格短时运行。没有做：

- 生产网格长时目标工况；
- `N/2N/4N` 空间独立加密；
- 时间步或容差独立加密；
- 输出采样间隔独立加密；
- 求解器交叉比较；
- 失张、重新受拉、压缩—屈曲事件专项收敛。

因此任何“生产数值已合格”“事件峰值已收敛”或“长时频率已可靠”的说法均不受本次证据支持。

### 3.3 没有完整 M0–M5 运行

本次只验证生成器能产生 M1–M5 overlay，并实际运行 M1。由于仓库缺少共用完整材料初态加载、M0 和自动相邻比较链，不能把现有结果描述为“完成了 M0–M5 消融”。

### 3.4 没有实验数据验证

本次没有获得或使用真实实验轨迹、材料标定数据、相机标定、不确定度样本或盲留出数据；也没有拟合任何真实参数。

因此不能评价：

- 哪个后端对真实绳材更准确；
- `EA`、`EI`、黏性、接头和支架参数的真实值；
- 预测误差是否在实验不确定度内；
- 模型是否能外推到未参与拟合的几何和初始条件。

### 3.5 没有发布或生产工程审查

用户已经明确 GUI 的目标是把理论算明白，不要求生产级或发布级。本次指出启动器、可移植性和 TOCTOU，是因为它们会影响科学复现和输入身份，而不是用商业软件标准扩大审查范围。

没有评估安装器、跨平台打包、无障碍、国际化、自动更新、长期服务运维或高并发。

## 4. 五级声明边界

后续报告应始终区分以下层级：

| 层级 | 需要的最低证据 | 当前状态 |
|---|---|---|
| 模型自洽 `MODEL_CONSISTENT` | 方程、符号、量纲、身份和代码路径一致 | 部分达到 |
| 代码验证 `CODE_VERIFIED` | 同提交全套测试、负测试、可复现环境全绿 | 未达到 |
| 数值资格 `NUMERICALLY_QUALIFIED` | 空间/时间/输出/求解器及事件量收敛 | 未运行，NO-GO |
| 实验验证 `EXPERIMENTALLY_VALIDATED` | 独立标定和未参与拟合的验证集 | 未运行 |
| 预测能力 `PREDICTIVE` | 冻结模型对盲留出/外推工况成功并报告不确定度 | 未建立 |

一个层级通过不能自动推出下一个层级。例如：

- 能量残差很小不等于物理模型正确；
- 网格收敛不等于实验正确；
- 拟合校准数据很好不等于能够盲预测；
- 某后端计算更精细不等于它对真实编织绳更高保真。

## 5. 对短时 HF 结果的限制

本次 A/B 运行专门用于回答“独立 `EI` 是否进入真实计算”。它们不适合回答频率、长期轨迹或事件问题：

- 只观察约 0.25 个候选周期；
- 候选频率位于搜索边界；
- 事件数为 0；
- 弯曲能占比约为百万分之几；
- 两次摆球位置差约 `6.19e-11 m`；
- 没有网格或时间加密对照。

所以这里的正确结论是“参数通路可执行且产生响应”，不是“`EI` 已被物理验证”。

## 6. 对结构性结果的限制

有限时间窗内轨迹闭合误差小，只能支持该窗口、该参数和该数值分辨率下的闭合证据。它不能单独证明：

- 严格锁频；
- 不变环面存在；
- 整个连续振幅域满足性质；
- 长时间稳定；
- 实验系统具有相同结构。

修订后的结构性审计工具在这一点上处理正确；本次通过的是“证据分类护栏的行为”，不是更强定理本身。

## 7. 为什么当前状态是 NO-GO，而不是永久否定

`NO_GO` 在本报告中表示“当前证据链不允许进入或通过该门槛”，不是说方法永远不可行。当前主要问题都有明确修复路径：

- NumPy API 兼容是局部代码问题；
- 冻结交付根可以重新生成；
- 事件资格可以加入运行身份和预冻结约束；
- M0–M5 可以实现共初态执行器；
- 证据等级可以改为机器生成；
- 生产矩阵可以在前置门槛全绿后运行。

因此建议状态是 `PARTIAL_REQUIRES_CORRECTIVE_COMMIT`，不是 `REJECT_ALL`。
