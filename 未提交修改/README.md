# 未提交修改

这里是仓库的默认工作区，保存尚未晋升到根目录成熟基线的开发、修复、审查、验证、文档和
数据候选。

**“未提交修改”不是 Git 状态。** 本目录内的阶段成果应正常 commit 和 push，以便 Codex、
网页版 Pro 或人工协作者从 GitHub 继续。只有完成验收和明确晋升后，内容才成为成熟基线。
仓库只使用 **main** 分支；本目录就是开发分支、候选分支和接力分支在文件系统中的替代物。

## 当前布局

~~~text
未提交修改/
├── README.md
└── 当前任务/
    ├── README.md
    ├── 候选实现或候选内容/
    ├── 管理/
    └── 审查与复现/
        ├── 当前审查/
        └── 历史审查/
~~~

默认只允许一个目录名为 **当前任务** 的活动接力入口。将来切换任务时，应先冻结并 push
当前状态，再把已结束任务迁入有日期和任务名的历史目录，最后建立新的 **当前任务**。

候选内部即使存在 **01_最终理论**、**02_最终模拟程序**、**03_项目资料** 或“最终版”等
名称，仍然只是工作区候选。
