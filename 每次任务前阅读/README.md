# 每次任务前阅读

这是仓库的强制接力入口。无论任务来自 Codex、网页版 Pro 还是人工协作者，都应先完成本页
列出的阅读和现场检查，再开始审查、开发、运行或晋升。

1. [01-仓库身份与目录边界.md](01-仓库身份与目录边界.md)
2. [02-当前状态与下一步.md](02-当前状态与下一步.md)

## 开始前的现场检查

至少确认以下事实，不能只照抄本目录中的历史状态：

~~~bash
git rev-parse --show-toplevel
git status --short --branch
git rev-parse HEAD
git remote -v
git for-each-ref --format='%(refname:short)' refs/heads
git ls-remote --heads origin
~~~

如果现场分支、HEAD、目录或工作树与
[02-当前状态与下一步.md](02-当前状态与下一步.md) 不一致，应先说明漂移并判断是否影响任务。
不得为了得到“干净”状态而丢弃不明修改。

## 权威关系

当前用户的明确指令优先，其次是根目录 **AGENTS.md** 和本控制区，再其次是当前任务管理文件。
候选目录内部的旧 README、manifest、日志和审查报告可能绑定历史提交；它们是证据来源，
但不能覆盖本控制区对“当前状态”的说明。

## 最短交接摘要

- 默认只在 **未提交修改/** 工作。
- **01_最终理论/**、**02_最终模拟程序/**、**03_项目资料/** 和根归档默认只读。
- 工作区成果可以且应当 commit/push；“未提交”指尚未晋升。
- Git 只使用 **main**；所有阶段成果直接提交并推送到 **main**，不另建分支。
- 当前候选未完成生产数值资格、实验验证或预测能力证明。
- 没有明确晋升授权时，不得修改成熟基线。
